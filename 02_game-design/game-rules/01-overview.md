# 01. 게임 개요와 핵심 수치

## 승패

| 결과 | 조건 |
|---|---|
| 승리 | 상대 영웅 체력이 0이 된다 (공격·마법·궁극기 어느 쪽이든) |
| 패배 | ① 내 영웅 체력이 0이 된다 ② 기권한다 |

덱이 0장이 되면 드로우만 생략하고, 이미 확보한 손패와 전장 카드로 영웅 체력이 0이 될 때까지 계속 싸웁니다.

- 승리하면 상대(Noctis)가 가진 크래커를 최대 200개 빼앗습니다 → [06](06-economy-and-deck.md).
- 혈마나(체력으로 비용 지불)는 영웅이 0이 되는 선택을 허용하지 않습니다. 지불 후 체력이 1 이상 남아야 합니다.

## 구성 요소

| 요소 | 설명 |
|---|---|
| 영웅 | 양쪽 각각 체력 100. 상대 영웅은 **상대 전장이 비었을 때만** 챔프로 직접 공격 가능 |
| 챔프 카드 | 소환해서 싸우는 캐릭터. 공격력·체력·소환 효과 보유 |
| 마법 카드 | 세팅해 두면 다음 필드(다음 내 턴 시작)에 발동하는 카드 |
| 함정 카드 | 세팅해 두면 조건이 맞을 때 자동 발동하는 반응형 카드 |
| 궁극기 | 손패의 챔프 카드를 궁극기 슬롯에 장착해 쓰는 한 방 기술 |
| 성격 오로라 | 전투 시작 때 고르는 불·물·나무·금속·대지 5종 패시브 |
| 덱 | 챔프 45장, 마법 9장, 함정 6장으로 구성된 60장 덱 → [06](06-economy-and-deck.md) |
| 묘지 | 쓰러졌거나 궁극기로 쓴 내 챔프. 부활 효과(소울 리턴)가 참조 |

## 핵심 수치 표

| 항목 | 값 | 코드 위치 |
|---|---|---|
| 영웅 최대 체력 | 100 (양쪽) | `HERO_MAX_HP` |
| 시작 마나 / 최대 마나 | 3 / 10 | `STARTING_MANA`, `MANA_CAP` |
| 마나 증가 | 내 턴이 시작될 때마다 최대치 +1, 마나 전부 회복 | `startPlayerTurn` |
| 내 전장 최대 | 6장 | `FIELD_CARD_LIMIT` |
| 손패 최대 | 8장 (가득 차면 뽑기·드로우가 막힘) | `drawCard`, `useDrawAction` |
| 덱 크기 | 정확히 60장 | `saveBattleDeck` |
| 같은 카드 덱 최대 장수 | 7장 (보유 수 이하) | `addToDraft` |
| 마법/함정 슬롯 | 2칸 | `setMagicCards` |
| 궁극기 | 배틀당 횟수 제한 없음, 사용한 카드는 묘지로 | [04](04-ultimate-and-comeback.md) |
| 혈마나 해금 | 3턴부터 | `BLOOD_MANA_UNLOCK_TURN` |
| 시작 크래커 | 300 | `defaultCollectionState` |

## 한 판의 큰 흐름

1. 전투 시작 → **성격 오로라 선택 화면**(불·물·나무·금속·대지 중 택1)
2. 초기 세팅: 양쪽 전장은 비어 있고, 내 손패는 저비용 챔프 2장을 포함한 7장으로 시작 → [02](02-turn-and-combat.md)
3. 내 턴(준비) → 턴 종료 → 내 챔프 자동 전투 → 상대 턴 → 반복
4. 영웅 체력이 0이 되거나 덱이 바닥나면 종료, 크래커 정산
