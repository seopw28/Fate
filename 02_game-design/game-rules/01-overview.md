# 01. 게임 개요와 핵심 수치

## 승패

| 결과 | 조건 |
|---|---|
| 승리 | 상대 소환사 체력이 0이 된다 (공격·마법·궁극기 어느 쪽이든) |
| 패배 | ① 내 소환사 체력이 0이 된다 ② 기권한다 |

덱이 0장이 되면 드로우만 생략하고, 이미 확보한 손패와 전장 카드로 소환사 체력이 0이 될 때까지 계속 싸웁니다.

- PvC 전투에서 승리하면 상대의 재화를 빼앗지 않고 **클리어 보상 크래커 200개와 쿠키조각 10개**를 받습니다 → [06](06-economy-and-deck.md).
- 혈마나(체력으로 비용 지불)는 소환사가 0이 되는 선택을 허용하지 않습니다. 지불 후 체력이 1 이상 남아야 합니다.

## 구성 요소

### PvC 상대 덱 원칙

- 기본 대전은 다른 이용자가 아니라 컴퓨터 상대와 싸우는 **PvC**입니다.
- 상대 덱의 콘텐츠 단위는 캐릭터챗 **한 작품**입니다. 한 작품에 등장하는 주요 인물을 가능한 한 모두 포함해, 작품의 관계와 분위기가 전장에 드러나는 올스타 덱을 구성합니다.
- 작품별 상대 덱은 대표 인물, 조연, 적대 인물과 작품 전용 마법·함정을 함께 사용합니다. 카드 풀이 60장에 부족하면 동일 인물의 변형 카드 또는 공용 마법으로 채우되 다른 작품의 캐릭터를 섞지 않습니다.
- 현재 목업의 Noctis 기본 덱은 작품별 카드 데이터가 연결되기 전까지 사용하는 임시 상대 덱입니다.

| 요소 | 설명 |
|---|---|
| 소환사 | 양쪽 각각 체력 100. 상대 소환사는 **상대 전장이 비었을 때만** 하수인으로 직접 공격 가능 |
| 하수인 카드 | 소환해서 싸우는 캐릭터. 공격력·체력·소환 효과 보유 |
| 마법 카드 | 세팅해 두면 다음 필드(다음 내 턴 시작)에 발동하는 카드 |
| 함정 카드 | 세팅해 두면 조건이 맞을 때 자동 발동하는 반응형 카드 |
| 궁극기 | 손패의 하수인 카드를 궁극기 슬롯에 장착해, 강화된 소진자를 전장 맨 오른쪽에 내려놓는 기술(전장이 가득 찼을 때만 맨 오른쪽 하수인을 제물로 보냄) |
| 성격 오라 | 전투 시작 때 고르는 불·물·나무·금속·대지 5종 패시브 |
| 덱 | 하수인 30장, 마법 20장, 함정 10장으로 구성된 60장 덱 → [06](06-economy-and-deck.md) |
| 묘지 | 전투 중 쓰러지거나 궁극기 제물·사용 처리된 내 하수인. 부활 효과(소울 리턴)가 참조하고, 덱에 하수인이 없을 때 카드 뽑기에서 체력 10을 내고 덱에 섞을 수 있음 |

## 핵심 수치 표

| 항목 | 값 | 코드 위치 |
|---|---|---|
| 소환사 최대 체력 | 100 (양쪽) | `HERO_MAX_HP` |
| 시작 마나 / 최대 마나 | 3 / 10 | `STARTING_MANA`, `MANA_CAP` |
| 마나 증가 | 내 턴이 시작될 때마다 최대치 +1, 마나 전부 회복 | `startPlayerTurn` |
| 내 전장 최대 | 5장 | `FIELD_CARD_LIMIT` |
| 손패 최대 | 8장 (가득 차면 뽑기·드로우가 막힘) | `drawCard`, `useDrawAction` |
| 덱 크기 | 정확히 60장 | `saveBattleDeck` |
| 같은 카드 덱 최대 장수 | 7장 (보유 수 이하) | `addToDraft` |
| 세팅 슬롯 | 함정 전용 1칸. 마법은 손패 더블클릭으로 즉시 발동 | `MAGIC_SLOT_KINDS`, `setMagicCards` |
| 궁극기 | 배틀당 횟수 제한 없음. 오라 각성 후 세팅, 비용은 최대 마나. 전장이 가득 차 있을 때만 맨 오른쪽 아군을 제물로 삼고, 소진자(기본 공격력 +7 / 체력 1, 오라 공명이면 +12 / 4)가 맨 오른쪽에 남아 전역 도발. 소진자가 쓰러진 뒤 세 번째 턴 시작에 복수자(+7/+15) 강림 | [04](04-ultimate-and-comeback.md) |
| 혈마나 해금 | 1턴부터 (제한 없음) | `BLOOD_MANA_UNLOCK_TURN` |
| 시작 크래커 | 300 | `defaultCollectionState` |

## 한 판의 큰 흐름

1. 전투 시작 → **성격 오라 선택 화면**(불·물·나무·금속·대지 중 택1)
2. 초기 세팅: 양쪽 전장은 비어 있고, 내 손패는 저비용 하수인 2장과 저비용 마법 1장을 포함한 5장으로 시작 → [02](02-turn-and-combat.md)
3. 내 턴(준비) → 턴 종료 → 내 하수인 자동 전투 → 상대 턴 → 반복
4. 어느 한쪽 소환사 체력이 0이 되면 종료하고 보상을 정산. 덱이 바닥나면 드로우만 생략하고 현재 손패와 전장으로 계속 전투
