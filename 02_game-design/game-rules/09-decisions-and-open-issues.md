## B. 미해결 이슈 / 위험 (우선순위순)

### 0. ✅ 보호막 이펙트 이미지 — 완료 (2026-11-03)
보호막 유지 오라와 피해 차단 순간의 파괴 버스트를 투명 이미지로 제작해 전투 런타임에 연결했습니다. `data-shield` 상태를 따라 오라가 자동으로 붙고 제거되며, 차단 시 `보호막이 막음 · 피해 0` 안내와 전용 파괴 이미지가 함께 표시됩니다. 제작 기록은 [`06_assets/art-queue.md`](../../06_assets/art-queue.md)의 P0에 있습니다.

(그림 없던 마법·함정 7장은 2026-11-02 사용자 제공 이미지로 해결. 다른 카드 그림을 같이 쓰던 마법 4장도 2026-11-03 교체 완료.)

### 1. ✅ (해결) 성격 오로라 선택 단계 재화 정산 제거

### 2. 🔴 상대 챔프가 있어도 영웅 직접 공격 가능 (버그 가능성)
내 챔프 선택 후 상대 영웅을 클릭하면 상대 전장에 챔프가 있어도 피해가 들어갑니다 (상대 챔프 1장, 공격력 4 챔프로 시험: 100 → 96). 코드(`attackFace`)가 "도발" 상태만 검사하고 상대 전장이 비었는지는 검사하지 않습니다. 자동 전투는 항상 맨 왼쪽 챔프부터 치므로 **수동 조작에서만** 우회됩니다. 의도라면 규칙으로 문서화, 아니라면 상대 전장이 비었을 때만 허용하도록 수정해야 합니다.

### 3. ✅ (해결) 저장 데이터가 "카드 번호"에 의존
저장할 때 `cardIds`를 함께 기록하고, 불러올 때 현재 카드 목록과 다르면 cardId 기준으로 자동 정렬합니다 (`remapSavedByCardIds`, 단위 테스트 6종). 이제 카드를 중간에서 삭제·삽입해도 기존 유저 저장 데이터가 어긋나지 않습니다.
- 남은 위험: **v6 이전에 제거된 카드 2장(레이븐·오스릭)은 마이그레이션 없이 지워졌기 때문에, 그 시점에 이미 어긋난 브라우저 저장 데이터는 복구되지 않습니다.** `cardIds`가 붙기 전 저장본은 보정 불가.

### 4. 🟠 JSON 파일이 git에 올라가지 않음 (카드 데이터 + `package.json`)
`.gitignore`의 `*.json` 규칙 때문에 `03_card-data/sets/*.json`**과 루트 `package.json`**이 추적되지 않습니다. 즉 `npm run qa:overflow`, `qa:economy` 같은 **npm 스크립트 정의도 버전 관리되지 않습니다.** 카드 수정 이력이 남지 않고, 다른 PC에서 원본을 잃으면 `cards.js`에서 역변환해야 합니다. `.gitignore`에 예외(`!03_card-data/**/*.json`)를 추가하는 것을 권장합니다.

### 4-1. 🔴 크래커는 클라이언트에서 조작 가능 (실결제 전 필수)
크래커·보유 카드·보상 정산이 전부 브라우저(localStorage)에서 일어나므로 개발자 도구로 누구나 값을 바꿀 수 있습니다. URL 옵션(`?crackers`, `?guardian`)은 개발 환경 전용으로 막았지만(`DEV_MODE`), **콘솔 조작은 클라이언트만으로는 막을 수 없습니다.** 실결제를 붙이기 전에 서버가 잔액·소환 결과·전투 보상을 검증하는 구조가 필요합니다.

### 5. 🟠 이미지 큐 (Codex 이미지 생성 한도 해제 후 처리, 2026-11-04 15:35 이후)
- 이모지/플레이스홀더 일러스트 마법·함정: Flame Sigil, Ambush Mine, Glacial Chain, Crimson Bolt, Spring of Restoration, Counter Current, Last Stand 등
- 프로스트 노바: 임시 현미경 눈결정 사진 (퍼블릭 도메인)
- 성격 오로라 인장(청·백·주·현)과 프로필 아이콘: 현재 글자 인장 임시
- 토큰(마력 늑대, 되살린 사령 등)은 최근 Codex로 교체됨. 추가 토큰이 생기면 같은 방식으로.

### 6. 🟠 해석·가정으로 구현된 것 (기획 확인 필요)
- **역전 돌진의 "총 체력"** = 영웅 체력 + 전장 챔프 체력 합 (영웅 체력만 볼 수도 있음)
- **궁극기로 쓴 카드가 묘지로** → 부활 효과로 되살릴 수 있게 한 해석
- 상대에게는 역전 돌진을 적용하지 않음(원래 소환 즉시 공격)

### 7. 🟡 카드 데이터와 코드의 불일치
- `deckLimit`(1~3장)이 UI에서 쓰이지 않고 전부 7장 규칙만 적용됨
- 규칙 문구 일부가 폐지된 규칙을 가리킴 (예: 관통 "확률 방어 무시")
- "도발" 판정 코드는 있으나 켜 주는 카드/규칙이 없음 (죽은 기능)
- 슬라임 전용 "분체 복제" 로직(`self-replicate`)이 코드에 남아 있음(카드는 삭제됨, 테스트가 확인 중)
- 상대 챔프의 소환 효과/능력이 작동하지 않음

### 8. 🟡 밸런스 검증의 한계
시뮬레이터(`09_balance-lab/match-simulator`)는 마법·함정·궁극기·혈마나·챔프 개별 능력을 모델링하지 않습니다. 대칭 모드는 양쪽 모두 소환 즉시 공격하므로 **역전 돌진·궁극기 2회 같은 최근 규칙은 측정되지 않았습니다.** 성격 오로라 승률 격차(약 1.5%p)는 참고 수치입니다. 실제 플레이 테스트가 필요합니다.

### 9. 🟡 기타
- 덱 편집/덱 상점 UI 개편 계획 (카드 디자인과 효과를 함께 보여 주는 덱 편성, 화려한 카드 오픈 연출, 두 메뉴 분리)은 요구사항 인터뷰 단계입니다. 확정된 설계 없음.
- 사운드: 피격 효과음·평타 모션은 변주 완료([10](10-audio-and-motion.md)). 남은 것: 스킬/마법별 고유음, 오로라 음원 보강(Elemental Forces $2 검토), 소리 크기 균형은 직접 들어 보고 조정 필요(헤드리스 환경에서는 청취 검증 불가).
- 동시 편집: 여러 세션이 `dist/index.html`을 동시에 수정하면 커밋이 섞입니다.
