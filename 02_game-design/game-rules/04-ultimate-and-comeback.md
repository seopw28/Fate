# 04. 궁극기, 역전 돌진, 최후의 저항

세 시스템 모두 "밀리고 있을 때, 또는 후반에 판을 뒤집는" 장치입니다.

## 1. 궁극기

### 기본 규칙
- **배틀당 횟수 제한은 없습니다** (`ULTIMATE_MAX_USES = Infinity`). 사용 가능 턴·마나 비용·장착할 챔프 카드, 그리고 직전 사용 뒤 6턴의 재세팅 대기가 자연스러운 제한입니다. 패널 제목 옆에 `횟수 제한 없음`이 표시됩니다.
- 궁극기는 **손패의 챔프 카드를 슬롯에 장착**해서 씁니다. 장착하면 그 카드는 손패에서 사라집니다.
  - 장착 방법: ① "궁극기 세팅하기" 버튼 → 손패 캐릭터 클릭 ② 카드를 패널로 드래그
  - 발동 전(준비 단계)에는 슬롯을 더블클릭하거나 손패로 드래그해 **장착을 취소**할 수 있습니다.
- 발동하면 **슬롯이 비워지고, 사용한 카드는 묘지로 이동**합니다. 다른 캐릭터를 다시 장착해 또 쓸 수 있습니다.
  - 묘지의 카드는 부활 효과(소울 리턴)로 되살릴 수 있습니다 (원래 체력으로).
- 발동은 **필드 중앙에 뜨는 버튼**으로 합니다. 조건이 안 되면 버튼에 이유가 표시됩니다 (예: `4턴부터 가능 (현재 3턴)`, `마나 8 필요`).

### 발동 조건 (모두 충족)
1. 궁극기 슬롯에 카드가 장착되어 있음
2. 준비 단계임 (전투 처리 중에는 불가)
3. 현재 턴 ≥ 사용 가능 턴. 단, 오라 각성 후 아직 이번 배틀에서 궁극기를 한 번도 사용하지 않았다면 최초 궁극기는 이 턴 제한을 무시
4. 마나 ≥ 궁극기 비용
5. 성격 오라별 추가 조건 충족

### 카드별 수치 계산

| 값 | 계산 |
|---|---|
| 강한 카드 여부 | 기본 비용 ≥ 5 **또는** 공격력 ≥ 7 |
| 궁극기 마나 비용 | `min(10, 기본 비용 + 2)` (강한 카드는 `+4`) |
| 사용 가능 턴 | 4턴부터 (강한 카드는 6턴부터) |
| 재사용 대기 | 사용한 턴으로부터 3턴 뒤부터 다시 가능 (`ULTIMATE_COOLDOWN_TURNS`). 최초 사용 가능 턴만 넘기면 연속 발동되는 것을 막음. 첫 사용 턴만 4/6턴으로 앞당겼고 재사용 규칙은 기존 값을 유지 |
| 재세팅 대기 (2026-11-07) | **최초 궁극기를 제외한 모든 궁극기는, 직전 궁극기를 사용한 턴으로부터 6턴이 지나야 슬롯에 세팅할 수 있습니다** (`ULTIMATE_RESET_TURNS`). 궁극기가 자주 나오면 주인공이 여럿인 느낌이 되어 무게가 사라지므로, 발동 쿨다운과 별개로 **슬롯에 올리는 것 자체**를 막습니다. 세팅 버튼·카드 클릭·드래그 경로를 모두 막고 패널에 남은 턴을 표시합니다 |

- **오라 각성 최초 궁극기 보정**: 영웅 체력 80 이하에서 오라 각성이 활성화되면, 그 배틀에서 아직 궁극기를 사용하지 않은 경우에만 일반 4턴·강한 카드 6턴의 최소 사용 턴을 해제합니다. 첫 궁극기 사용 뒤에는 각성 중이어도 이후 궁극기의 턴 제한과 재사용 대기를 기존 규칙대로 적용합니다. 마나와 전장 제물은 최초 궁극기에도 그대로 필요합니다.

### 성격 오라별 효과

| 성격 오라 | 이름 | 효과 |
|---|---|---|
| 불 | 홍련 종언 | 상대 영웅에게 `공격력 + 기본비용 + 5` 피해 |
| 물 | 빙해 봉인 | 모든 적 챔프에게 `⌈공격력/2⌉ + 3` 피해, 공격력 −2 |
| 바람 | 천공 해방 | 모든 아군 공격 +3(강한 카드 +4), 즉시 행동 가능 |
| 대지 | 절대성역 | **절대방어**: 다음 상대 턴 동안 아군 챔프 전체와 내 영웅이 피해를 받지 않음(내 턴 시작에 해제). 강한 카드는 쓰러진 챔프 1명을 **부활**(체력 절반) |
| 금속 | 운명 절단 | 상대 영웅에게 `공격력 + 6` 피해 후 카드 2장 드로우 |

- 궁극기는 불리한 상황을 타파하는 수단이므로 속성별 체력·전장 수·성격 조합 조건을 두지 않습니다. 공통 제한은 마나, 최초 사용 가능 턴, 재사용 대기, 재세팅 대기 6턴, 아군 제물 1장입니다.
- 발동하면 필드 중앙 연출이 재생되고 약 2.5초 뒤 효과가 적용됩니다. 효과로 상대 영웅이 0이 되면 즉시 승리합니다.
- **전장 제물 규칙**: 궁극기는 내 전장에 제물로 삼을 챔프가 1장 이상 있으면 발동할 수 있습니다. 전장이 6장이어도 발동 가능하며, 맨 오른쪽 챔프를 제물로 보내 비운 자리에 궁극기 세팅 카드를 공격력 0·체력 1로 배치합니다. 이 궁극기 소진 카드는 순서 변경이 불가능하며, 다른 카드 역시 그보다 오른쪽으로 이동할 수 없습니다.
- **공격력 0 보장**: 궁극기 소진자는 카드와 영웅 모두에게 전투 피해를 주지 못합니다. 오라·연속 공격·필드 등 추가 공격 보너스가 있더라도 최종 전투 피해는 0을 유지합니다.
- **전역 도발**: 궁극기 소진 카드가 전장에 살아 있는 동안 상대의 모든 단일 기본 공격은 위치·난이도·일반 도발보다 우선해 반드시 이 카드를 대상으로 합니다. 소진 카드를 제거하기 전에는 다른 아군 카드나 내 영웅을 기본 공격할 수 없습니다. 광역 공격과 마법 효과는 이 대상 제한을 받지 않습니다. 상태는 카드의 두꺼운 짙은 회색 장갑 테두리로 표시하며, 카드 경계 밖에 별도 텍스트 배지를 띄우지 않습니다.
- **소진자 사망 연출**: 공격력 0·체력 1의 궁극기 소진 카드가 죽으면 일반 사망 연출 대신 화면 중앙에서 카드를 크게 확대한 뒤 둘로 찢어져 소멸시킵니다. 카피는 메인 타이틀 `복수의 시작`, 별도 이름 행 `{{소진자 이름}}`, 설명 `소진자의 죽음이 복수를 부릅니다` 순서로 분리해 표시합니다. 후속 복수자 강림의 감정적 대비를 만드는 필수 연출입니다.
- **컴퓨터 상대 대칭 규칙**: 컴퓨터도 손패 챔프를 궁극기에 장착하고, 플레이어와 같은 마나·최소 턴·재사용 대기·전장 제물 규칙을 적용합니다. 장착과 발동 카드를 중앙에 공개하고, 맨 오른쪽 챔프를 제물로 보낸 뒤 `0/1` 소진자를 전장에 배치합니다. 소진자는 플레이어의 모든 기본 공격을 우선해서 받습니다.
- **프로토타입 동료 매칭**: 현재는 최초로 궁극기를 사용한 카드와 같은 속성의 다른 카드 1장을 현재 덱 구성에서 무작위로 매칭합니다. 이는 카드별 동료 데이터가 준비되기 전까지만 쓰는 임시 폴백이며 최종 규칙이 아닙니다.
- **정식 동료 데이터 요구사항**: 추후에는 모든 고유 카드마다 전용 `companionCardId`와 별도 동료 일러스트를 콘텐츠 데이터에 미리 설정해야 합니다. 정식 동료는 현재 덱에 포함된 일반 카드를 런타임에 찾는 방식이 아니며, 카드별로 지정된 전용 동료와 전용 일러스트를 반드시 불러와야 합니다. 해당 데이터 도입 시 프로토타입 덱 내 무작위 매칭은 제거합니다.

## 2. 역전 돌진

> 한 줄 요약: **내 영웅 체력이 최대 체력의 40% 이하이면, 새로 소환한 챔프가 소환 즉시 공격할 수 있다.**

- **발동 조건**: 내 영웅 체력 `≤ 40` (`DESPERATE_HP_RATIO = 0.4`, 최대 체력 100 기준). 전장 챔프의 체력이나 상대 체력은 판정에 포함하지 않습니다.
- **효과**: 조건이 켜진 상태에서 소환한 챔프는 "행동 완료" 상태가 되지 않아, 그 턴 종료 시 전투에 참여합니다. 소환 직후 수동 공격도 가능합니다.
- 판정은 **소환하는 순간**의 체력으로 합니다(소환하는 카드 자신은 계산에서 제외). 이미 전장에 있던 챔프에는 영향이 없습니다.
- 카드를 고르면 안내 문구 뒤에 `· 역전 돌진`이 붙고, 소환하면 "역전 돌진 · 즉시 공격" 효과와 전투 로그가 나옵니다.
- 효과 토큰(마력 늑대 등)은 카드를 내는 게 아니라서 대상이 아닙니다.
- 역전 돌진은 플레이어 전용 반격 장치이며 상대에게는 적용하지 않습니다. 상대도 일반적으로 소환한 턴에는 공격하지 못하고, 게일 러시·디멘션 이지스처럼 즉시 행동을 명시한 효과만 예외입니다.

## 3. 최후의 저항 (시각 연출)

역전 돌진과 **같은 조건**(영웅 체력이 최대 체력의 40% 이하)이 되면 해당 편의 체력 게이지가 격렬하게 변합니다. 이 상태가 곧 **역전 돌진이 켜진 상태**이며, 안내 연출이 그 효과(소환 즉시 공격)를 함께 설명합니다.

| 연출 | 내용 |
|---|---|
| 게이지 | 붉은 테두리·바깥 빛이 심장박동처럼 맥동, 막대에 끓는 줄무늬, 깜빡임, 미세한 떨림 |
| 중앙 안내 | 필드 중앙에 타이핑으로 `최후의 저항이 시작되었습니다.` (상대는 `상대의 …`)를 쓴 뒤, **효과 설명 연출**이 이어집니다. 양쪽 모두 추가 드로우와 복수자 강림 조건을 안내하며, 플레이어에게는 역전 돌진 조작 설명도 함께 표시합니다. 약 6초 |
| 소리 | 심장 소리 두 번 + 타이핑 효과음 |
| 반복 | 중앙 안내는 **한 배틀에 각 편 최초 1번만** 표시. 회복해서 벗어났다가 다시 들어가도 안내는 다시 뜨지 않음(게이지 연출과 로그는 계속 반영) |
| 접근성 | "움직임 줄이기" 설정이면 애니메이션 없이 정적 붉은 테두리만 |

- **추가 드로우**: 내가 최후의 저항 상태이면 내 턴 시작에 덱에서 카드를 **1장 더** 받습니다 (손패 8장이 차 있거나 덱이 비면 생략). 중앙 안내의 효과 설명에도 함께 표시됩니다.
- **상대 추가 드로우**: 컴퓨터 상대도 최후의 저항 상태이면 자기 턴 시작에 덱에서 카드를 **1장 더** 받습니다.
- **복수자 카드 식별**: 복수자로 강림한 카드는 기존 카드 형태와 이름 영역을 그대로 유지하고 왕관 등 별도 장식물을 붙이지 않습니다. 전장에서는 일반 카드보다 정확히 10% 크게 표시하며, 현재 오라 계열색을 사용한 3px 테두리와 외곽 광휘를 적용해 강함을 구분합니다. 확대된 복수자는 인접 카드보다 위 레이어에 표시합니다.
- **영웅 회복 잠금**: 내 영웅이 한 번 최후의 저항 상태(현재 최대 체력 100 기준 40 이하)에 들어가면, 그 배틀이 끝날 때까지 내 영웅 본체 체력은 회복되지 않습니다. 체력 30에서 진입한 경우도 동일합니다. 영웅 회복 카드·소환 효과·역전 마법·취소 환급의 체력 복구는 모두 0으로 처리하고, 챔피언 카드의 체력 회복은 정상 적용합니다. 이는 각성 BGM 전환 상태를 되돌리지 않고 긴급 국면을 유지하기 위한 규칙입니다.
- **복수자 강림 (배틀당 1회)**: **최초 궁극기 소진자가 전장에서 쓰러지고**, 내 체력이 40 이하이면 매칭된 같은 속성 동료가 최초 궁극기 사용자의 원래 능력치를 기준으로 `공격력 +3 / 체력 +10` 상태로 소환됩니다. 두 조건은 순서와 무관하게 **모두** 충족해야 하며, 소진자가 전장에 살아 있는 동안에는 체력이 40 이하여도 강림하지 않고 사망 시점까지 보류합니다. 궁극기를 한 번도 쓰지 않았다면 복수의 기준이 되는 소진자 자체가 없으므로 강림하지 않습니다. 같은 속성의 다른 동료를 현재 덱에서 매칭할 수 없으면 후보가 생길 때까지 소환을 보류합니다. 일반 소환이 아니라 궁극기급 전면 컷씬에서 동료 일러스트를 확대하고, `{{복수 기준 카드 이름}}의 복수를 하고 말겠어!` 대사를 표시한 뒤 전장에 착지합니다. 착지 순간 전장 전체가 크게 내려앉고 좌우로 흔들리며, 착지점을 중심으로 다중 충격파·화면 섬광·강한 저음이 재생됩니다. 이 충격과 동시에 상대 전장에 있는 모든 챔프에게 각각 5 피해를 줍니다. 이미 전장이 6장이면 가장 오른쪽 챔프를 교체합니다. 이미 체력 40 이하인 상태에서 소진자가 쓰러지면 전용 사망 컷이 끝난 직후 이어서 강림합니다.
- **컴퓨터 복수자 대칭 규칙**: 상대도 **자기 궁극기 소진자가 쓰러지고** 체력 40 이하이면 같은 조건으로 `공격력 +3 / 체력 +10` 복수자를 배틀당 1회 강림시키며, 같은 컷신과 착지 충격을 사용하고 내 전장 전체에 각각 5 피해를 줍니다. 동료 후보는 장착 궁극기, 최근 사망 카드, 보유 챔프 순으로 확정하되, 소진자가 쓰러지기 전에는 플레이어와 동일하게 강림을 보류합니다.
- **복수 연결 사망 연출 (배틀당 1회)**: 복수의 기준이 되는 **최초 궁극기 사용자**가 궁극기 소진 상태에서 죽을 때만 전용 사망 컷과 효과음을 약 4초간 충분히 보여 줍니다. 이후 궁극기 사용자의 죽음은 일반 사망 연출을 사용합니다. 최후의 저항 안내, 이 전용 사망 컷, 복수자 강림과 등장 피해는 서로 겹치지 않도록 순차 처리합니다.
- **보상 교체 결정**: 복수자의 등장 광역 피해를 추가하는 대신, 최후의 저항에서 제공하던 `첫 발동 턴 마법카드 1장 즉시 발동` 기능과 관련 배지·안내는 제거합니다. 마법카드는 다시 기존 규칙대로 슬롯에 세팅한 뒤 발동합니다.
- 최후의 저항은 최대 마나 상한을 늘리지 않습니다. 최대 마나는 항상 10입니다.
- 상대 게이지도 같은 조건에서 같은 연출이 납니다(연출 전용).
