# 04. 궁극기, 역전 돌진, 최후의 저항

세 시스템 모두 "밀리고 있을 때, 또는 후반에 판을 뒤집는" 장치입니다.

## 1. 궁극기

### 기본 규칙
- **배틀당 횟수 제한은 없습니다** (`ULTIMATE_MAX_USES = Infinity`). 사용 가능 턴·마나 비용·장착할 챔프 카드가 자연스러운 제한입니다. 패널 제목 옆에 `횟수 제한 없음`이 표시됩니다.
- 궁극기는 **손패의 챔프 카드를 슬롯에 장착**해서 씁니다. 장착하면 그 카드는 손패에서 사라집니다.
  - 장착 방법: ① "궁극기 세팅하기" 버튼 → 손패 캐릭터 클릭 ② 카드를 패널로 드래그
  - 발동 전(준비 단계)에는 슬롯을 더블클릭하거나 손패로 드래그해 **장착을 취소**할 수 있습니다.
- 발동하면 **슬롯이 비워지고, 사용한 카드는 묘지로 이동**합니다. 다른 캐릭터를 다시 장착해 또 쓸 수 있습니다.
  - 묘지의 카드는 부활 효과(소울 리턴)로 되살릴 수 있습니다 (원래 체력으로).
- 발동은 **필드 중앙에 뜨는 버튼**으로 합니다. 조건이 안 되면 버튼에 이유가 표시됩니다 (예: `4턴부터 가능 (현재 3턴)`, `마나 8 필요`).

### 발동 조건 (모두 충족)
1. 궁극기 슬롯에 카드가 장착되어 있음
2. 준비 단계임 (전투 처리 중에는 불가)
3. 현재 턴 ≥ 사용 가능 턴
4. 마나 ≥ 궁극기 비용
5. 성격 오라별 추가 조건 충족

### 카드별 수치 계산

| 값 | 계산 |
|---|---|
| 강한 카드 여부 | 기본 비용 ≥ 5 **또는** 공격력 ≥ 7 |
| 궁극기 마나 비용 | `min(10, 기본 비용 + 2)` (강한 카드는 `+4`) |
| 사용 가능 턴 | 4턴부터 (강한 카드는 6턴부터) |
| 재사용 대기 | 사용한 턴으로부터 3턴 뒤부터 다시 가능 (`ULTIMATE_COOLDOWN_TURNS`). 최초 사용 가능 턴만 넘기면 연속 발동되는 것을 막음. 첫 사용 턴만 4/6턴으로 앞당겼고 재사용 규칙은 기존 값을 유지 |

### 성격 오라별 효과와 조건

| 성격 오라 | 이름 | 추가 조건 | 효과 |
|---|---|---|---|
| 불 | 홍련 종언 | 내 영웅 체력 75 이하 | 상대 영웅에게 `공격력 + 기본비용 + 5` 피해 |
| 물 | 빙해 봉인 | 상대 챔프 2명 이상 | 모든 적 챔프에게 `⌈공격력/2⌉ + 3` 피해, 공격력 −2 |
| 바람 | 천공 해방 | 아군 챔프 2명 이상 | 모든 아군 공격 +3(강한 카드 +4), 즉시 행동 가능 |
| 대지 | 절대성역 | 내 영웅 체력 67 이하 | **절대방어**: 다음 상대 턴 동안 아군 챔프 전체와 내 영웅이 피해를 받지 않음(내 턴 시작에 해제). 강한 카드는 쓰러진 챔프 1명을 **부활**(체력 절반) |
| 금속 | 운명 절단 | 내 전장에 서로 다른 성격 오라 3종 | 상대 영웅에게 `공격력 + 6` 피해 후 카드 2장 드로우 |

- 체력 조건(75, 67)은 영웅 최대 체력(100)의 비율(75%, 2/3)로 계산됩니다. 최대 체력을 바꾸면 자동으로 따라갑니다.
- 발동하면 필드 중앙 연출이 재생되고 약 2.5초 뒤 효과가 적용됩니다. 효과로 상대 영웅이 0이 되면 즉시 승리합니다.
- **전장 제물 규칙**: 궁극기는 내 전장이 1~5장일 때만 발동할 수 있습니다. 발동하면 맨 오른쪽 챔프를 제물로 보내고, 궁극기 세팅 카드를 공격력 0·체력 1로 맨 오른쪽에 배치합니다. 이 궁극기 소진 카드는 순서 변경이 불가능하며, 다른 카드 역시 그보다 오른쪽으로 이동할 수 없습니다. 내 전장이 6장이면 궁극기를 사용할 수 없습니다.
- **전역 도발**: 궁극기 소진 카드가 전장에 살아 있는 동안 상대의 모든 단일 기본 공격은 위치·난이도·일반 도발보다 우선해 반드시 이 카드를 대상으로 합니다. 소진 카드를 제거하기 전에는 다른 아군 카드나 내 영웅을 기본 공격할 수 없습니다. 광역 공격과 마법 효과는 이 대상 제한을 받지 않습니다.
- **소진자 사망 연출**: 공격력 0·체력 1의 궁극기 소진 카드가 죽으면 일반 사망 연출 대신 화면 중앙에서 카드를 크게 확대한 뒤 둘로 찢어져 소멸시키고, `소진자의 죽음이 복수를 부릅니다`를 표시합니다. 후속 복수자 강림의 감정적 대비를 만드는 필수 연출입니다.
- **프로토타입 동료 매칭**: 현재는 최초로 궁극기를 사용한 카드와 같은 속성의 다른 카드 1장을 현재 덱 구성에서 무작위로 매칭합니다. 이는 카드별 동료 데이터가 준비되기 전까지만 쓰는 임시 폴백이며 최종 규칙이 아닙니다.
- **정식 동료 데이터 요구사항**: 추후에는 모든 고유 카드마다 전용 `companionCardId`와 별도 동료 일러스트를 콘텐츠 데이터에 미리 설정해야 합니다. 정식 동료는 현재 덱에 포함된 일반 카드를 런타임에 찾는 방식이 아니며, 카드별로 지정된 전용 동료와 전용 일러스트를 반드시 불러와야 합니다. 해당 데이터 도입 시 프로토타입 덱 내 무작위 매칭은 제거합니다.

## 2. 역전 돌진

> 한 줄 요약: **내 영웅 체력이 최대 체력의 40% 이하이면, 새로 소환한 챔프가 소환 즉시 공격할 수 있다.**

- **발동 조건**: 내 영웅 체력 `≤ 40` (`DESPERATE_HP_RATIO = 0.4`, 최대 체력 100 기준). 전장 챔프의 체력이나 상대 체력은 판정에 포함하지 않습니다.
- **효과**: 조건이 켜진 상태에서 소환한 챔프는 "행동 완료" 상태가 되지 않아, 그 턴 종료 시 전투에 참여합니다. 소환 직후 수동 공격도 가능합니다.
- 판정은 **소환하는 순간**의 체력으로 합니다(소환하는 카드 자신은 계산에서 제외). 이미 전장에 있던 챔프에는 영향이 없습니다.
- 카드를 고르면 안내 문구 뒤에 `· 역전 돌진`이 붙고, 소환하면 "역전 돌진 · 즉시 공격" 효과와 전투 로그가 나옵니다.
- 효과 토큰(마력 늑대 등)은 카드를 내는 게 아니라서 대상이 아닙니다.
- 상대 챔프는 원래 소환 즉시 공격하므로 상대에게 별도 규칙은 없습니다.

## 3. 최후의 저항 (시각 연출)

역전 돌진과 **같은 조건**(영웅 체력이 최대 체력의 40% 이하)이 되면 해당 편의 체력 게이지가 격렬하게 변합니다. 이 상태가 곧 **역전 돌진이 켜진 상태**이며, 안내 연출이 그 효과(소환 즉시 공격)를 함께 설명합니다.

| 연출 | 내용 |
|---|---|
| 게이지 | 붉은 테두리·바깥 빛이 심장박동처럼 맥동, 막대에 끓는 줄무늬, 깜빡임, 미세한 떨림 |
| 중앙 안내 | 필드 중앙에 타이핑으로 `최후의 저항이 시작되었습니다.` (상대는 `상대의 …`)를 쓴 뒤, **효과 설명 연출**이 이어진다: `역전 돌진 발동` 태그 + 소환 카드가 내려앉고 바로 공격하는 미니 애니메이션 + `새로 소환한 챔프가 소환한 그 턴에 바로 공격할 수 있습니다.` + 조건. 상대용은 `상대 챔프는 원래 소환 즉시 공격하므로 추가 효과는 없습니다.` 약 6초 |
| 소리 | 심장 소리 두 번 + 타이핑 효과음 |
| 반복 | 중앙 안내는 **한 배틀에 각 편 최초 1번만** 표시. 회복해서 벗어났다가 다시 들어가도 안내는 다시 뜨지 않음(게이지 연출과 로그는 계속 반영) |
| 접근성 | "움직임 줄이기" 설정이면 애니메이션 없이 정적 붉은 테두리만 |

- **마법카드 즉시 발동 (1회)**: 최후의 저항이 **처음 발동된 그 내 턴**에 한해, 손패의 마법카드 1장을 세트하지 않고 바로 발동할 수 있습니다. 비용(마나·혈마나)은 그대로 내고, 마법 슬롯이 차 있어도 쓸 수 있습니다. 함정은 대상이 아닙니다. 상대 턴 중에 발동됐다면 바로 다음 내 턴이 그 턴입니다. 해당 카드에는 `즉시 발동` 배지가 붙고, 그 턴이 지나면 사라집니다.
- **추가 드로우**: 내가 최후의 저항 상태이면 내 턴 시작에 덱에서 카드를 **1장 더** 받습니다 (손패 8장이 차 있거나 덱이 비면 생략). 중앙 안내의 효과 설명에도 함께 표시됩니다.
- **복수자 강림 (배틀당 1회)**: 최초 궁극기 사용 후 내 체력이 40 이하가 되면, 매칭된 같은 속성 동료가 최초 궁극기 사용자의 원래 능력치를 기준으로 `공격력 +3 / 체력 +10` 상태로 소환됩니다. 일반 소환이 아니라 궁극기급 전면 컷씬에서 동료 일러스트를 확대하고, `{{최초 궁극기 사용자 이름}}의 복수를 하고 말겠어!` 대사를 표시한 뒤 전장에 착지합니다. 이미 전장이 6장이면 체력 1의 최초 궁극기 소진자를 우선 교체합니다. 이미 체력 40 이하에서 최초 궁극기를 썼다면 즉시 발동합니다.
- 최후의 저항은 최대 마나 상한을 늘리지 않습니다. 최대 마나는 항상 10입니다.
- 상대 게이지도 같은 조건에서 같은 연출이 납니다(연출 전용).
