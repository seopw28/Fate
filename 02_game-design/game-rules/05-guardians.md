# 05. 성격의 오라

전투가 시작되면 **성격의 오라 선택 화면**이 열립니다. 불·물·나무·금속·대지 중 하나를 무료로 선택하며, 상대 AI는 플레이어가 고르지 않은 오라 중 하나를 무작위로 사용합니다.

오라 문양은 한자나 글자를 쓰지 않는 전용 SVG입니다. 불꽃·물결·가지·결정·지층의 기하 형태로 구분하며 프로필, 선택 화면, 각성 연출과 카드 뒷면에서 같은 자산을 재사용합니다.

> 저장 데이터와 개발용 URL 호환을 위해 내부 식별자 `jujak`, `cheongryong`, `namu`, `baekho`, `hyeonmu`는 유지합니다. 사용자에게는 이전 신 이름이나 사신 이름을 표시하지 않습니다.

## 1. 오라 5종

| 성격 오라 | 내부 id | 발동 시점 | 확률 | 효과 |
|---|---|---|---:|---|
| 불 · 열정 | `jujak` | 내 챔프의 기본 공격·반격으로 적 챔프가 피해를 받고 생존 | 30% | 대상에게 2턴간 화상. 대상의 턴 시작마다 피해 1 |
| 물 · 포용 | `cheongryong` | 비용 2 이상 카드를 낼 때 | 27% | 마나 1~2 회복 (컴퓨터도 같은 트리거·확률·상한) |
| 나무 · 발전 | `namu` | 내 턴 시작 | 카드마다 78% | 필드 카드 체력 +1 |
| 금속 · 냉철 | `baekho` | 내 턴 시작 | 생존 턴마다 +26%p(최대 90%) | 맨 왼쪽 챔프가 배틀 중 한 번 공격력 +4 |
| 대지 · 무던 | `hyeonmu` | 내 챔프가 치명 피해를 받을 때 | 1.5% | 체력 1로 생존(한 배틀 최대 1회, 관통 공격에는 무효) |

## 2. 오라 각성

- 내 영웅 체력이 처음 85 이하가 되면 선택창에서 현재 오라의 강화 2개 중 하나를 고릅니다. 상대 AI도 같은 체력 기준에서 A/B 중 하나를 무작위로 선택합니다.
- 선택한 강화는 체력이 회복되어도 배틀 종료까지 유지되며 변경할 수 없습니다. 궁극기 사용 여부와는 무관하고 마나를 소비하지 않습니다.

| 오라 | 선택지 A | 선택지 B |
|---|---|---|
| 불 | 불길 확산: 기본 공격·반격으로 생존한 적 챔프에게 40% 확률로 5턴간 화상, 대상 턴 시작마다 피해 1 | 업화: 20% 확률로 2턴간 업화, 대상 턴 시작마다 피해 3 |
| 물 | 범람: 비용 2 이상 카드 사용 시 4.5% 확률로 마나 7 회복 | 순환: 비용 2 이상 카드 사용 시 27% 확률로 마나 2 회복 |
| 나무 | 숲의 생명: 내 턴 시작 시 전장에 있는 모든 아군의 최대·현재 체력 +2 | 거목 수호: 내 턴 시작 시 35% 확률로 가장 왼쪽 아군의 최대·현재 체력 +5 |
| 금속 | 숙련 가속: 생존 턴마다 확률 +42%p(최대 100%), 성공 시 배틀 중 한 번 공격력 +4 | 연속베기: 기본 공격 시 10% 확률로 다른 적 챔프를 우선해 공격력 50%로 한 번 더 공격. 다른 적이 없으면 같은 대상을 재공격하며 추가 타격에는 반격이 다시 발생하지 않음 |
| 대지 | 암반 피부: 4코스트 이상 아군이 피해를 받을 때 12% 확률로 피해 1 감소, 최소 피해 1 | 절대방어: 피해를 받을 때 1.2% 확률로 피해를 완전히 무효화 |

- **주작 오라 화상**은 기본 공격과 100% 상호 피해의 반격에서 각각 독립적으로 판정합니다. 챔프에게만 적용하고 피해량은 중첩하지 않으며, 재부여하면 피해량과 남은 지속 시간을 각각 더 큰 값으로 갱신합니다. 피해는 대상 측 턴 시작 시 다른 행동보다 먼저 적용됩니다.
- 카드 효과의 일반 `화상 N`은 주작 오라 화상과 별도 상태입니다. 같은 대상에게 여러 번 부여하면 수치가 합산되고, 플레이어 전투 종료 후 합산 수치만큼 한 번 피해를 준 뒤 해제됩니다 → [02](02-turn-and-combat.md#6-상태이상표식).
- 금속의 생존 턴은 카드별로 보존됩니다. 맨 왼쪽 자리가 바뀌면 새 선두 카드가 실제로 생존한 턴을 사용하며, 공격력 보상은 카드마다 배틀 중 한 번만 받습니다.
- 대지의 암반 피부는 피해를 최소 1까지 줄이며, 절대방어는 피해가 적용되기 전에 피해를 완전히 무효화합니다.
- 밸런스 비교 단위는 **기본 오라 5종 × 각성 A/B = 10개 선택지**입니다. 각 선택지의 종합 승률은 자기 자신을 제외한 나머지 9개 선택지를 같은 비율로 만나고, 양쪽 좌석을 50:50으로 교환한 대칭 시뮬레이션으로 측정합니다.
- 시뮬레이터는 마법·함정·궁극기·혈마나·챔프 개별 능력을 모델링하지 않으므로 결과는 오라 자체의 상대 강도를 보는 방향성 지표입니다. 100% 상호 피해와 화상·생존 경험 개편을 반영한 2026-11-06 세 시드·선택지당 총 6만 판에서 최고 50.60%, 최저 49.60%로 격차가 1.00%p였습니다. 상세 결과는 [`aura-mutual-damage-burn-and-metal-2026-11-06.md`](../../09_balance-lab/balance-reports/aura-mutual-damage-burn-and-metal-2026-11-06.md)에 기록합니다.

| 오라 | 자산 |

| 물 | `dist/assets/auras/water-sigil.svg` |

모든 문양은 128×128 `viewBox`와 투명 배경을 사용합니다. 카드 뒷면 작업에서는 새 문양을 다시 그리지 않고 위 경로를 참조합니다.

## 4. 개발/QA 옵션

- `?guardian=cheongryong|baekho|jujak|namu|hyeonmu|none`은 기존 자동화 호환을 위한 개발 환경 전용 주소입니다.
- 신규 코드에서는 개념 이름을 `성격 오라`로 사용하되, 주소 파라미터와 저장 id는 마이그레이션 전까지 유지합니다.
