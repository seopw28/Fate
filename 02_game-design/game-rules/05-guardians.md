# 05. 수호신

전투가 시작되면 **수호신 선택 화면**이 열립니다. 올림포스의 신 4명(제우스·포세이돈·하데스·아테나) 중 하나를 고르거나, 아무것도 고르지 않는 "약자멸시"를 선택합니다. 화면은 신 4명이 **2×2 사분면**으로 놓이고, 약자멸시는 그 아래 가로 띠입니다. 선택 후 영웅 프로필(아바타)이 한글 인장(제·포·하·아)으로 바뀌고 이름 칩이 표시됩니다.

> 예전 동서남북 사신(청룡·백호·주작·현무)을 2026-11-03에 그리스 신으로 바꿨습니다. 능력·수치는 그대로이고, 저장 데이터·개발 옵션 호환을 위해 코드 내부 id는 예전 이름을 유지합니다: `jujak`=제우스, `cheongryong`=포세이돈, `hyeonmu`=하데스, `baekho`=아테나.

## 1. 수호신 4종

수치는 `dist/index.html`의 `GUARDIANS` 객체가 **유일한 출처**이며, 밸런스 시뮬레이터도 이 객체를 직접 읽습니다.

| 수호신 | 별칭 (내부 id) | 발동 시점 | 확률 | 효과 |
|---|---|---|---|---|
| 포세이돈 | 바다의 지배자 (`cheongryong`) | 비용 2 이상 카드를 낼 때 | 60% | 마나 1~2 회복 |
| 아테나 | 전쟁의 지혜 (`baekho`) | 내 챔프가 공격을 받고 **살아남았을 때** | 60% | 공격력의 15%로 즉시 반격 (최소 1·최대 2 피해) |
| 제우스 | 천공의 왕 (`jujak`) | 카드를 뽑을 때 | 25% | 그 카드가 S급(공격력 +3)이 됨. 선택 전에 정해지는 **시작 손패에는 적용 안 됨** |
| 하데스 | 저승의 왕 (`hyeonmu`) | 내 챔프가 **치명 피해**를 받을 때 | 5% | 체력 1로 생존 (**한 판 최대 1회**). 관통(`armor-pierce`) 공격에는 무효 |

- 상대 AI도 수호신을 가집니다. **내가 고른 것을 제외한 나머지 중 무작위**로 배정됩니다. 약자멸시를 고르면 4종 중 무작위입니다.
- 모든 수호신은 확률형 패시브라서 편차가 큽니다. 2026-11-04 조정 후 3개 시드·9만 판 시뮬레이터 기준 수호신 간 승률 격차는 약 1.4%p입니다. 단, 시뮬레이터는 마법·궁극기·혈마나를 모델링하지 않아 실제 플레이 테스트로 보정이 필요합니다.

### 수호신 궁극기 · 신성 강림

- 일반 궁극기를 1회 실제 발동한 **다음 내 턴부터** 해금되며, 별도 고정 턴 제한과 마나 소모 없이 한 배틀에 한 번 발동합니다. 첫 궁극기와 같은 턴에는 연계할 수 없습니다.
- 발동한 1턴 동안 패시브 확률을 100%로 만들고 수호신마다 별도의 각성 능력을 부여합니다.
- 아테나는 반격 시 적 전장 전체에 2~5 피해, 포세이돈은 비용 2 이상 카드 사용 시 마나 4~7 회복, 제우스는 드로우 카드를 신화급(공격력 +5~8)으로 강화합니다. 하데스는 그 턴 처음 사망하는 아군 하나를 최대 체력으로 부활시킵니다.
- 각성 수치는 `적 필드 카드 수 - 내 필드 카드 수`가 클수록 강해지며, 하데스는 카드 격차와 무관하게 1회 완전 부활합니다.
- 수호신 강림 버튼은 전장 중앙의 일반 궁극기 조건과 같은 행에 표시됩니다.
- 각성 중에는 수호신 효과가 확정 발동하며, 필드 격차가 바뀌면 아테나·포세이돈·제우스의 각성 수치도 즉시 갱신됩니다.
- 기존 챔피언 장착 궁극기와 별도 버튼으로 제공되며, 약자멸시에서는 사용할 수 없습니다.

## 2. 약자멸시 (수호신 없음)

| 항목 | 내용 |
|---|---|
| 의미 | 수호신 없이 싸우는 도전 모드 |
| 선불 | 없음 (0) |
| 패배 시 | 크래커 200개 소모 (보유량이 부족하면 가진 만큼) |
| **기권 시** | **패배로 계산** → 200 소모 (기권은 모든 모드에서 패배 처리 하나로 합쳐져 이중 차감 없음) |
| **중도 이탈 시** | 끝내지 않고 새로고침·탭 닫기 → **다음 접속 때 패배(200)로 정산** (선택 시 "진행 중" 표식을 저장했다가 정상 종료 때 지움) |
| 승리 시 | 일반과 같이 상대에게서 크래커 최대 200 획득 |
| 표시 | 영웅 프로필이 `약`, 이름 칩이 `약자멸시` |

## 3. 크래커 정산 (수호신 관련)

| 상황 | 크래커 변화 |
|---|---|
| 수호신 선택 | **−100** (선불, 보유량이 100 미만이면 선택 불가 — 카드가 비활성) |
| 약자멸시 선택 | 0 (선불 없음) |
| 승리 | **+최대 200** (상대 보유량 200이 상한. 상대 크래커는 전투마다 200으로 시작) |
| 약자멸시로 패배 | **−200** |
| 기권 (일반 수호신) | **−최대 200** (패배로 계산, 상대에게 전달) |
| 기권 (약자멸시) | **−200** (패배로 계산) |
| 약자멸시 중도 이탈 | **−200** (다음 접속 때 정산) |

### 기대값(EV) 균형 근거 (2026-11-01 조정)

시뮬레이터 기준 승률을 수호신 50%, 약자멸시 46%로 가정했을 때:

| 선택 | 이기면 | 지면 | EV |
|---|---|---|---|
| 수호신 (선불 100) | +200 −100 = +100 | −100 | **0** |
| 약자멸시 | +200 | −200 | **−16** |

- 이전(선불 200)에는 수호신 EV가 −100이라 **아무도 수호신을 고를 이유가 없었습니다.** 선불을 100으로 낮춰 두 선택이 균형을 이룹니다. 수호신이 약간 유리하게 설계된 상태입니다.
- 승률 가정은 시뮬레이터(마법·궁극기 미반영) 기반이라 **실제 플레이 데이터로 재검증**해야 합니다. 조정은 `GUARDIAN_COST`, `VICTORY_STEAL`, `CHALLENGE_LOSS_COST` 세 상수로 합니다.

## 4. 개발/QA 옵션

- 주소에 `?guardian=cheongryong|baekho|jujak|hyeonmu|none`을 붙이면 선택 화면 없이 **무료로** 해당 수호신으로 시작합니다. **개발 환경(localhost 등)에서만 동작**하고 배포 주소에서는 무시됩니다.
- 선택 화면 자체는 `openGuardianSelect()`로 다시 띄울 수 있습니다.
