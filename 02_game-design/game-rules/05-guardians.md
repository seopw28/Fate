# 05. 성격의 오로라

전투가 시작되면 **성격의 오로라 선택 화면**이 열립니다. 불·물·나무·금속·대지 중 하나를 무료로 선택하며, 상대 AI는 플레이어가 고르지 않은 오로라 중 하나를 무작위로 사용합니다.

오로라 문양은 한자나 글자를 쓰지 않는 전용 SVG입니다. 불꽃·물결·가지·결정·지층의 기하 형태로 구분하며 프로필, 선택 화면, 각성 연출과 카드 뒷면에서 같은 자산을 재사용합니다.

> 저장 데이터와 개발용 URL 호환을 위해 내부 식별자 `jujak`, `cheongryong`, `namu`, `baekho`, `hyeonmu`는 유지합니다. 사용자에게는 이전 신 이름이나 사신 이름을 표시하지 않습니다.

## 1. 오로라 5종

| 성격 오로라 | 내부 id | 발동 시점 | 확률 | 효과 |
|---|---|---|---:|---|
| 불 · 열정 | `jujak` | 카드를 뽑을 때 | 25% | 그 카드가 S급(공격력 +3)이 됨. 시작 손패에는 적용하지 않음 |
| 물 · 포용 | `cheongryong` | 비용 2 이상 카드를 낼 때 | 60% | 마나 1~2 회복 |
| 나무 · 발전 | `namu` | 내 턴 시작 | 카드마다 60% | 필드 카드 체력 +1 |
| 금속 · 냉철 | `baekho` | 내 챔프가 공격을 받고 생존 | 60% | 공격력의 15%로 즉시 반격(최소 1·최대 2) |
| 대지 · 무던 | `hyeonmu` | 내 챔프가 치명 피해를 받을 때 | 5% | 체력 1로 생존(한 배틀 최대 1회, 관통 공격에는 무효) |

## 2. 오로라 각성

- 일반 궁극기를 1회 발동한 **다음 내 턴부터** 무료로 한 번 사용할 수 있습니다.
- 각성은 1턴 동안 유지되며 해당 오로라 패시브를 확정 발동시킵니다.
- 금속은 전역 반격, 물은 대량 마나 회복, 불은 신화급 드로우, 대지는 첫 사망 아군 완전 부활, 나무는 아군 전체 체력 증가 효과를 얻습니다.
- 각성 위력은 `적 필드 카드 수 - 내 필드 카드 수`가 클수록 강해집니다. 대지의 완전 부활은 필드 격차와 무관합니다.
- 각성 중 장착 궁극기의 **성격 계열이 오로라와 같으면 오로라 공명**이 적용됩니다. 궁극기 마나 비용이 2 감소(최소 1)하고, 최초 사용 가능 턴이 1턴 당겨지며, 일반 재사용 대기를 무시합니다.
- 오로라 공명도 궁극기 고유의 전장·체력 발동 조건은 제거하지 않습니다.

## 3. 문양 자산

| 오로라 | 자산 |
|---|---|
| 불 | `dist/assets/auras/fire-sigil.svg` |
| 물 | `dist/assets/auras/water-sigil.svg` |
| 나무 | `dist/assets/auras/wood-sigil.svg` |
| 금속 | `dist/assets/auras/metal-sigil.svg` |
| 대지 | `dist/assets/auras/earth-sigil.svg` |

모든 문양은 128×128 `viewBox`와 투명 배경을 사용합니다. 카드 뒷면 작업에서는 새 문양을 다시 그리지 않고 위 경로를 참조합니다.

## 4. 개발/QA 옵션

- `?guardian=cheongryong|baekho|jujak|namu|hyeonmu|none`은 기존 자동화 호환을 위한 개발 환경 전용 주소입니다.
- 신규 코드에서는 개념 이름을 `성격 오로라`로 사용하되, 주소 파라미터와 저장 id는 마이그레이션 전까지 유지합니다.
