# 05. 성격의 오라

전투가 시작되면 **성격의 오라 선택 화면**이 열립니다. 불·물·나무·금속·대지 중 하나를 무료로 선택하며, 상대 AI는 플레이어가 고르지 않은 오라 중 하나를 무작위로 사용합니다.

오라 문양은 한자나 글자를 쓰지 않는 전용 SVG입니다. 불꽃·물결·가지·결정·지층의 기하 형태로 구분하며 프로필, 선택 화면, 각성 연출과 카드 뒷면에서 같은 자산을 재사용합니다.

> 저장 데이터와 개발용 URL 호환을 위해 내부 식별자 `jujak`, `cheongryong`, `namu`, `baekho`, `hyeonmu`는 유지합니다. 사용자에게는 이전 신 이름이나 사신 이름을 표시하지 않습니다.

## 1. 오라 5종

| 성격 오라 | 내부 id | 발동 시점 | 확률 | 효과 |
|---|---|---|---:|---|
| 불 · 열정 | `jujak` | 내 챔프가 기본 공격할 때 | 6% | 첫 공격 후 살아 있으면 즉시 한 번 더 공격. 첫 대상이 쓰러지면 다음 앞줄 또는 영웅을 공격 |
| 물 · 포용 | `cheongryong` | 비용 2 이상 카드를 낼 때 | 60% | 마나 1~2 회복 |
| 나무 · 발전 | `namu` | 내 턴 시작 | 카드마다 60% | 필드 카드 체력 +1 |
| 금속 · 냉철 | `baekho` | 내 챔프가 공격을 받고 생존 | 60% | 공격력의 15%로 즉시 반격(최소 1·최대 2) |
| 대지 · 무던 | `hyeonmu` | 내 챔프가 치명 피해를 받을 때 | 5% | 체력 1로 생존(한 배틀 최대 1회, 관통 공격에는 무효) |

## 2. 오라 각성

- 내 영웅 체력이 처음 70 이하가 되면 선택창에서 현재 오라의 강화 2개 중 하나를 고릅니다.
- 선택한 강화는 체력이 회복되어도 배틀 종료까지 유지되며 변경할 수 없습니다. 궁극기 사용 여부와는 무관하고 마나를 소비하지 않습니다.

| 오라 | 선택지 A | 선택지 B |
|---|---|---|
| 불 | 폭열: 4.2% 확률로 총 3회 공격 | 연격: 7.5% 확률로 총 2회 공격 |
| 물 | 범람: 비용 2 이상 카드 사용 시 27% 확률로 마나 4~5 회복 | 순환: 항상 마나 2 회복 |
| 나무 | 숲의 생명: 내 턴 시작 시 전장에 있는 모든 아군의 최대·현재 체력 +1 | 거목 수호: 내 턴 시작 시 30% 확률로 가장 왼쪽 아군의 최대·현재 체력 +5 |
| 금속 | 절단 반격: 생존 시 50% 확률로 공격자에게 공격력 40% 반격, 피해 2~5 | 땅울림: 생존 시 15% 확률로 적 전장 전체에 피해 3 |
| 대지 | 절대방어: 피해를 받을 때 3.5% 확률로 피해를 완전히 무효화 | 불굴: 치명 피해를 받을 때 9.5% 확률로 체력 1 생존, 최대 2회 |

- 불의 추가 공격은 다시 오라 발동을 판정하지 않습니다. 대지의 불굴은 관통 공격에 발동하지 않으며, 절대방어는 피해가 적용되기 전에 피해를 완전히 무효화합니다.
- 양쪽 좌석을 50:50으로 교환한 3만 판/선택지 대칭 시뮬레이션에서 10개 선택지의 승률 범위는 49.7~50.2%이며, 동일 오라 A/B 직접 대결은 49.6~50.4%입니다.

## 3. 문양 자산

| 오라 | 자산 |
|---|---|
| 불 | `dist/assets/auras/fire-sigil.svg` |
| 물 | `dist/assets/auras/water-sigil.svg` |
| 나무 | `dist/assets/auras/wood-sigil.svg` |
| 금속 | `dist/assets/auras/metal-sigil.svg` |
| 대지 | `dist/assets/auras/earth-sigil.svg` |

모든 문양은 128×128 `viewBox`와 투명 배경을 사용합니다. 카드 뒷면 작업에서는 새 문양을 다시 그리지 않고 위 경로를 참조합니다.

## 4. 개발/QA 옵션

- `?guardian=cheongryong|baekho|jujak|namu|hyeonmu|none`은 기존 자동화 호환을 위한 개발 환경 전용 주소입니다.
- 신규 코드에서는 개념 이름을 `성격 오라`로 사용하되, 주소 파라미터와 저장 id는 마이그레이션 전까지 유지합니다.
