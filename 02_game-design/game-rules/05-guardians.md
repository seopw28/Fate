# 05. 수호신

전투가 시작되면 **수호신 선택 화면**이 열립니다. 동서남북 네 방위의 수호신 중 하나를 고르거나, 아무것도 고르지 않는 "약자멸시"를 선택합니다. 선택 후 영웅 프로필(아바타)이 한글 인장(청·백·주·현)으로 바뀌고 이름 칩이 표시됩니다.

## 1. 수호신 4종

수치는 `dist/index.html`의 `GUARDIANS` 객체가 **유일한 출처**이며, 밸런스 시뮬레이터도 이 객체를 직접 읽습니다.

| 수호신 | 방위 | 발동 시점 | 확률 | 효과 |
|---|---|---|---|---|
| 청룡 | 동 | 비용 2 이상 카드를 낼 때 | 35% | 마나 2 회복 |
| 백호 | 서 | 내 챔프가 공격을 받고 **살아남았을 때** | 8% | 즉시 반격 (자기 공격력만큼 공격자에게 피해, 공격자가 죽을 수 있음) |
| 주작 | 남 | 카드를 뽑을 때 | 20% | 그 카드가 S급(공격력 +3)이 됨. 선택 전에 정해지는 **시작 손패에는 적용 안 됨** |
| 현무 | 북 | 내 챔프가 **치명 피해**를 받을 때 | 3% | 체력 1로 생존 (**한 판 최대 1회**). 관통(`armor-pierce`) 공격에는 무효 |

- 상대 AI도 수호신을 가집니다. **내가 고른 것을 제외한 나머지 중 무작위**로 배정됩니다. 약자멸시를 고르면 4종 중 무작위입니다.
- 모든 수호신은 확률형 패시브라서 편차가 큽니다. 시뮬레이터 기준 최종 조정 결과는 수호신 간 승률 격차 약 1.5%p입니다 (`09_balance-lab/balance-reports/guardian-balance-2026-10-31.md`). 단, 시뮬레이터는 마법·필살기·혈마나를 모델링하지 않아 실제 플레이 테스트로 보정이 필요합니다.

## 2. 약자멸시 (수호신 없음)

| 항목 | 내용 |
|---|---|
| 의미 | 수호신 없이 싸우는 도전 모드 |
| 선불 | 없음 (0) |
| 패배 시 | 크래커 200개 소모 (보유량이 부족하면 가진 만큼) |
| **기권 시** | **패배로 계산** → 200 소모 (일반 기권의 20 전달과 별개, 이중 차감 없음) |
| **중도 이탈 시** | 끝내지 않고 새로고침·탭 닫기 → **다음 접속 때 패배(200)로 정산** (선택 시 "진행 중" 표식을 저장했다가 정상 종료 때 지움) |
| 승리 시 | 일반과 같이 상대에게서 크래커 최대 200 획득 |
| 표시 | 영웅 프로필이 `약`, 이름 칩이 `약자멸시` |

## 3. 크래커 정산 (수호신 관련)

| 상황 | 크래커 변화 |
|---|---|
| 수호신 선택 | **−100** (선불, 보유량이 100 미만이면 선택 불가 — 카드가 비활성) |
| 약자멸시 선택 | 0 (선불 없음) |
| 승리 | **+최대 200** (상대 보유량 200이 상한. 상대 크래커는 전투마다 200으로 시작) |
| 약자멸시로 패배 | **−200** |
| 기권 (일반 수호신) | **−최대 20** (상대에게 전달) |
| 기권 (약자멸시) | **−200** (패배로 계산) |
| 약자멸시 중도 이탈 | **−200** (다음 접속 때 정산) |

### 기대값(EV) 균형 근거 (2026-11-01 조정)

시뮬레이터 기준 승률을 수호신 50%, 약자멸시 46%로 가정했을 때:

| 선택 | 이기면 | 지면 | EV |
|---|---|---|---|
| 수호신 (선불 100) | +200 −100 = +100 | −100 | **0** |
| 약자멸시 | +200 | −200 | **−16** |

- 이전(선불 200)에는 수호신 EV가 −100이라 **아무도 수호신을 고를 이유가 없었습니다.** 선불을 100으로 낮춰 두 선택이 균형을 이룹니다. 수호신이 약간 유리하게 설계된 상태입니다.
- 승률 가정은 시뮬레이터(마법·필살기 미반영) 기반이라 **실제 플레이 데이터로 재검증**해야 합니다. 조정은 `GUARDIAN_COST`, `VICTORY_STEAL`, `CHALLENGE_LOSS_COST` 세 상수로 합니다.

## 4. 개발/QA 옵션

- 주소에 `?guardian=cheongryong|baekho|jujak|hyeonmu|none`을 붙이면 선택 화면 없이 **무료로** 해당 수호신으로 시작합니다. **개발 환경(localhost 등)에서만 동작**하고 배포 주소에서는 무시됩니다.
- 선택 화면 자체는 `openGuardianSelect()`로 다시 띄울 수 있습니다.
