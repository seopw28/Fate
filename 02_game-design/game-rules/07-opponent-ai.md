# 07. 상대 AI와 공정성 장치

상대는 "그림자 사냥꾼 Noctis" 한 명이며, 플레이어 티어에 맞춘 난이도로 매칭됩니다. 대전 중에는 컴퓨터 여부를 숨기고 승패가 확정된 결과 화면에서 공개합니다. 규칙은 대부분 플레이어와 같지만 **몇 가지가 의도적으로 다릅니다.**

## 1. 플레이어와 다른 점

| 항목 | 플레이어 | 상대 AI |
|---|---|---|
| 소환 직후 공격 | 불가 (행동 완료 상태). 역전 돌진·돌진 효과일 때만 가능 | **즉시 공격** |
| 챔프 능력(소환 효과 등) | 작동 | **작동하지 않음** (공격력·체력만 사용) |
| 마법/함정/궁극기 | 사용 | **사용하지 않음** (덱이 챔프뿐) |
| 마나 | 내 최대 마나 | 내 최대 마나와 **같은 값** (공정성 장치) |
| 손패 | 8장 | 5장에서 시작, 매 턴 1장 드로우 |
| 영웅 체력 | 100 | 100 |
| 전장 한도 | 6장 | 6장 |
| 크래커 | 내 보유량 | 전투마다 200으로 시작 (승리 시 최대 200을 빼앗김) |

## 2. 상대 AI의 판단 (매 턴)

1. **마나 갱신**: 그 턴 내 최대 마나와 같은 값으로 설정 (`ENEMY_AI.manaMirrorsPlayer`, 끄면 예전의 "남은 마나에 +1" 방식).
2. **소환 계획**: 손패에서 낼 수 있는 모든 카드 조합(최대 12장 중)을 평가해 가장 높은 점수의 조합을 **한 턴에 여러 장** 소환합니다.
   - 점수 = `Σ(공격력 × 1.0 + 체력 × 0.7)` + `사용 마나 × 0.35` + `전장 속성 시너지 보너스 × 1.5`
   - 시너지: 공명(같은 속성 2장 이상)·조화(속성 3종 이상)가 생기는 조합에 가산점.
   - 마나 한도와 빈 전장 칸 수 안에서만 고릅니다. 즉 **초반에 마나 이상의 카드를 낼 수 없습니다.**
3. **배치**: `공격력 − 체력 × 0.5`가 낮은(체력이 높고 공격력이 낮은) 챔프를 **왼쪽(앞줄)** 에 둡니다. 내 챔프는 맨 왼쪽부터 맞히므로 주력 딜러를 뒤에서 보호합니다.
4. **공격**: 모든 챔프가 순서대로 내 맨 왼쪽 챔프를 공격하고, 내 전장이 비어 있으면 내 영웅을 칩니다. (공격은 반격이 없으므로 "안 때리는 선택"은 없습니다.)

튜닝용 값: `ENEMY_AI = { manaMirrorsPlayer, atkWeight, hpWeight, manaWeight, synergyWeight }` (`dist/index.html`)

## 3. 시작 공정성

- **초기 전장 장수**: `OPENING_FIELD_SIZE`(현재 0 = 빈 전장). 2로 올리면 아래 규칙이 적용됩니다.
  - 양쪽 모두 **시작 마나(3) 이하 비용** 카드만 배치.
  - 상대의 초기 카드 전력(공격력+체력 합)이 내 전력을 **넘지 않도록** 후보 12장 중에서 고릅니다. (내가 약한 카드를 뽑았을 때 후보가 부족하면 1~2점 차로 넘을 수 있음. 80회 시험에서 74회 상대 ≤ 나, 나머지 6회도 +1~2점 이내.)
- **선공권**: 체력이 더 낮은 쪽 → 전장 챔피언이 더 적은 쪽 → 티어가 더 낮은 쪽 → 무작위 순으로 정합니다 → [02](02-turn-and-combat.md). 상대가 선공이면 내 준비 단계 전에 상대가 먼저 소환·공격합니다.

## 4. 알려진 한계

- 상대 챔프의 소환 효과·능력이 작동하지 않아 카드 설명과 다르게 행동합니다 (기획 의도라면 문서화, 아니면 구현 필요).
- 상대는 마법·함정·궁극기를 쓰지 않으므로 후반 난이도가 낮을 수 있습니다.
- 수호신은 무작위 배정이라 난이도가 판마다 다릅니다.
