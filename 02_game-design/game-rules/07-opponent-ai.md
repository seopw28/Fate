# 07. 상대 AI와 공정성 장치

상대는 "그림자 사냥꾼 Noctis" 한 명이며, 전투 시작 시 **초보자·나이트메어·헬** 중 컴퓨터 난이도를 선택합니다. 선택한 난이도는 상대 이름 옆에 계속 표시됩니다. 규칙은 대부분 플레이어와 같지만 **몇 가지가 의도적으로 다릅니다.**

## 1. 컴퓨터 난이도

| 난이도 | 판단 깊이 | 실수율 | 행동 방식 |
|---|---:|---:|---|
| 초보자 | 즉시 가치 | 35% | 합법적인 후보 중 차선 행동을 자주 선택하고 공격 대상도 무작위로 고름 |
| 나이트메어 | 전장 상황 1단계 | 10% | 공격·체력과 오라 시너지, 현재 열세 여부를 함께 평가 |
| 헬 | 제한적 2단계 | 0% | 다음 교환의 노출 피해까지 평가하고, 쓰러뜨릴 수 있는 고위협 대상을 우선 공격 |

세 난이도는 **같은 마나, 같은 카드 등급 확률, 같은 영웅 체력, 같은 소환 대기 규칙**을 사용합니다. 피해 배율이나 숨겨진 보정은 없습니다. 차이는 행동 후보 평가와 실수율뿐입니다.

난이도 선택 화면에는 내부 판단 방식 대신 프로토타입용 **예상 승률**(초보자 72%, 나이트메어 24%, 헬 4%)을 표시합니다. 현재 수치는 실제 이용자 전적이 아닌 임시 연출값이며, 전적 데이터가 충분히 쌓이면 난이도별 실측 승률로 교체합니다.

## 2. 플레이어와 다른 점

| 항목 | 플레이어 | 상대 AI |
|---|---|---|
| 소환 직후 공격 | 불가 (행동 완료 상태). 역전 돌진·돌진 효과일 때만 가능 | 불가. 새 챔프는 다음 상대 턴부터 공격 |
| 챔프 능력(소환 효과 등) | 작동 | 작동. 상대 진영을 기준으로 같은 효과 적용 |
| 마법/함정/궁극기 | 사용 | 사용. 마법·함정은 최대 2장 세트, 궁극기는 동일한 최소 턴·마나·조건·재사용 대기 적용 |
| 마나 | 내 최대 마나 | 내 최대 마나와 동일 |
| 손패 | 8장 | 5장에서 시작, 매 턴 1장 드로우 |
| 영웅 체력 | 100 | 100 |
| 전장 한도 | 6장 | 6장 |
| 크래커 | 내 보유량 | 전투마다 200으로 시작 (승리 시 최대 200을 빼앗김) |

## 3. 상대 AI의 판단 (매 턴)

1. **마나 갱신**: 그 턴 내 최대 마나와 같은 값으로 설정합니다.
2. **마법·궁극기 판단**: 준비된 세트 마법을 해석하고, 궁극기의 최소 턴·마나·전장 조건·재사용 대기를 확인해 발동합니다. 남은 마나로 함정과 다음 필드 마법을 최대 2장까지 세트합니다.
3. **소환 계획**: 남은 손패에서 낼 수 있는 모든 챔프 조합(최대 12장 중)을 평가해 난이도별 판단 깊이와 실수율에 따라 조합을 선택합니다.
   - 점수 = `Σ(공격력 × 1.0 + 체력 × 0.7)` + `사용 마나 × 0.35` + `전장 오라 시너지 보너스 × 1.5`
   - 시너지: 공명(같은 오라 2장 이상)·조화(오라 3종 이상)가 생기는 조합에 가산점.
   - 마나 한도와 빈 전장 칸 수 안에서만 고릅니다. 즉 **초반에 마나 이상의 카드를 낼 수 없습니다.**
   - 여러 장을 선택해도 화면에 동시에 생성하지 않습니다. AI 계산과 전체 턴 템포는 빠르게 유지하되, 실제 선택 순서대로 약 0.2초 간격을 두고 한 장씩 공개·착지시킵니다. 소환 효과로 이어지는 추가 카드도 같은 표시 대기열을 따릅니다.
4. **배치**: `공격력 − 체력 × 0.5`가 낮은(체력이 높고 공격력이 낮은) 챔프를 **왼쪽(앞줄)** 에 둡니다. 내 챔프는 맨 왼쪽부터 맞히므로 주력 딜러를 뒤에서 보호합니다.

궁극기 소진 `0/1` 카드의 전역 도발은 모든 난이도의 공격 대상 판단보다 우선합니다. 해당 카드가 살아 있으면 AI는 다른 카드나 영웅을 기본 공격 대상으로 선택할 수 없습니다.
5. **공격**: 초보자는 합법적인 대상을 무작위로, 나이트메어는 앞줄부터, 헬은 이번 공격으로 쓰러뜨릴 수 있는 고위협 챔프를 우선 선택합니다. 도발은 모든 난이도에서 우선합니다.
6. **오라 각성**: 초보자는 A/B를 무작위로 고르고, 나이트메어·헬은 양쪽 전장 장수와 현재 마나를 바탕으로 공격·광역·성장·방어 선택지를 고릅니다.

튜닝용 값: `ENEMY_AI = { manaMirrorsPlayer, atkWeight, hpWeight, manaWeight, synergyWeight }` (`dist/index.html`)

## 4. 시작 공정성

- **초기 전장 장수**: `OPENING_FIELD_SIZE`(현재 0 = 빈 전장). 2로 올리면 아래 규칙이 적용됩니다.
  - 양쪽 모두 **시작 마나(3) 이하 비용** 카드만 배치.
  - 상대의 초기 카드 전력(공격력+체력 합)이 내 전력을 **넘지 않도록** 후보 12장 중에서 고릅니다. (내가 약한 카드를 뽑았을 때 후보가 부족하면 1~2점 차로 넘을 수 있음. 80회 시험에서 74회 상대 ≤ 나, 나머지 6회도 +1~2점 이내.)
- **선공권**: 체력이 더 낮은 쪽 → 전장 챔피언이 더 적은 쪽 → 무작위 순으로 정합니다 → [02](02-turn-and-combat.md). 상대가 선공이면 내 준비 단계 전에 상대가 먼저 소환·공격합니다.

## 5. 알려진 한계

- 현재 헬은 완전한 게임 트리 탐색이 아니라 **마법 가치·궁극기 조건·챔프 소환·배치·공격·오라 각성을 각각 평가하는 전술 AI**입니다.
- 성격 오라는 무작위 배정이라 난이도가 판마다 다릅니다.
