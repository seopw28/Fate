# 10. 효과음과 평타 모션

> 피해 소리가 "픽! 픽!"으로 단조롭고 평타 모션이 전원 똑같다는 피드백에서 출발했습니다 (TEAM_REVIEW, 2026-11-01).
> 코드: `05_game-client/battle/sfx-variety.js`, `attack-motions.js` (빌드 시 `dist/runtime/`으로 복사)

## 1. 피격 효과음

### 원칙
- **모든 피격은 피해량과 무관하게 같은 "강한 신호"** 로 울립니다 (피해 강도에 따른 소리 단계 없음).
- 같은 소리의 반복을 막는 변주는 **조합·음높이·타이밍·좌우 위치**로 만듭니다.
- **공간감은 속성마다 다르게** 줍니다. 모두 같은 잔향이면 구별이 안 되고, 칼날처럼 예리해야 하는 소리가 둔해지기 때문입니다.

### 구성: 몸통 + 어택 + 질감 + 공간
한 번 칠 때마다 아래 층이 겹쳐 재생됩니다.

| 층 | 내용 |
|---|---|
| ① 몸통(body) | 길게 울리는 기존 샘플(폭발·금속·칼). 속성별로 음높이·필터·꼬리 길이를 달리해 무게를 만든다 |
| ② 어택(accent) | Kenney Impact Sounds(CC0)의 짧은 타격음. 매번 다른 변형(5종)을 골라 질감을 바꾼다 |
| ③ 질감 | 잡음·공명(resonator) 기반 합성음 1~2개. (예전의 삑 하는 순수 톤은 장난감 소리 같아서 제거) |
| ④ 공간 | 잔향 + 좌우 폭(Haas) + 압축기 + 속성별 EQ |

### 속성별 공간·음색 (구별을 위해 일부러 다르게)

| 속성 | 소리 성격 | 공간(잔향) | 꼬리 | 측정(꼬리 / 잔향 비율) |
|---|---|---|---|---|
| 불 | **처음 쓰던 폭발 샘플 원본**을 가공 없이 (EQ·음높이·다른 샘플 섞기·합성음 없음). 크기만 원본보다 약 2.5dB 낮춤 | 거의 없음(원본이 가진 울림) | 길다 | 약 1.0초 / 63% |
| 물 | 유리·얼음·물 주문 샘플. **공간감 없이 건조하게**, 처음 소리를 4번 겹쳐 튀는 물방울·물결처럼. 불처럼 들리던 폭발 샘플은 쓰지 않는다 | **없음 (0)** | 짧다 | 약 0.3~0.5초 / 약 1% |
| 바람 | **예리한 칼날**: 칼 샘플을 높은 음(+20%)으로, 저음 600Hz 이하 제거, 고음 강조. 장난감 소리 같던 금속판·종 샘플 제외. 처음 소리를 3번 겹쳐 여러 번 스치는 칼바람처럼 | 작은 방 · 거의 없음 | 아주 짧다 | 약 0.2초 / 0% |
| 대지 | **더 낮고 크게**, 공간감 가장 넓음 (음높이 −18%, 고음 제한, 강한 저음 EQ, 홀 잔향 38%·좌우 폭 40%) | 홀 · **가장 많음** | 가장 길다 | 약 1.1초 / 61% |
| 무속성 | 금속 울림 | 작은 방 · 적음 | 짧다 | 약 0.5초 / 23% |

- 전체 울림 길이는 처음 설계(잔향 1.7초·꼬리 2.0초)의 **70% 이하**로 줄였습니다 (잔향 1.15초, 꼬리 1.4초).
- 속성마다 조합 후보가 5개이고, **직전에 쓴 조합은 제외**하고 고릅니다. 샘플도 종류마다 5개 변형 중 직전과 다른 것을 고릅니다.
- 매번 음높이(±5%), 볼륨(±10%), 겹치는 타이밍이 조금씩 달라지고, 맞은 대상이 화면 왼쪽이면 왼쪽에서 들립니다.

### 겹쳐 내기 (물·바람): 공간감을 넣는 대신 처음 소리를 여러 번
- 물과 바람은 잔향으로 공간감을 만들기보다 **처음 소리(어택)를 짧은 간격으로 여러 번 겹쳐서** 낼 때 더 속성답다는 피드백을 반영했다.
- 몸통(길게 울리는 샘플)은 **한 번만** 내고, 조합의 첫 층(어택)만 반복한다. 반복음은 짧게 끊어(0.16~0.22초) 하나하나 구별되게 한다.

| 속성 | 반복 횟수 | 간격 | 볼륨 감쇠 | 음높이 | 좌우 |
|---|---|---|---|---|---|
| 물 | 4번 (처음 + 3번) | 40~75ms | 반복마다 ×0.7 | 반복마다 +3% (±5% 무작위) | 번갈아 좌우로 번짐 |
| 바람 | 3번 (처음 + 2번) | 30~55ms | 반복마다 ×0.74 | 반복마다 +6% (±3% 무작위) | 번갈아 좌우로 번짐 |

- 연속 타격이 쌓이면 반복 횟수도 줄인다 (최소 50%).
- 검증: 샘플 대신 짧은 클릭음을 넣고 합성음을 끈 채 세어 보면 물은 2.4번 → 5.2번(약 42ms 간격), 바람은 2.1번 → 3.6번으로 늘어난다.
- 조절: `ELEMENT.water.stack` / `ELEMENT.wind.stack`의 `count`(횟수), `spacing`(간격), `decay`(감쇠), `cap`(반복음 길이). 끄려면 `stack`을 지운다. 바꾼 뒤에는 `--calibrate`를 다시 돌린다.

### 페이드아웃 (꼬리가 뚝 끊기지 않게)
- **문제였던 것**: 길게 울리는 샘플을 정점 근처로 유지하다가 정해진 지점에서 한꺼번에 줄여서, 소리가 "뚝" 끊기는 느낌이 났다.
- **지금 방식**: 꼬리 길이(cap)의 **40% 지점(속성별 `fade`)** 에서 **지수적으로 완만하게** 줄이기 시작해 cap에서 약 −60dB(사실상 무음)에 도달한다. 마지막 20ms는 짧게 0으로 마무리해 클릭도 없앴다. 자연 길이로 끝나는 짧은 샘플도 마지막 20ms를 부드럽게 마무리한다.
- 칼날(바람)은 예리하게 사라지도록 **10%** 로 일찍 시작한다.
- 연속 타격 때 이전 잔향을 누르는 속도도 15ms → 60ms로 느리게, 깊이는 0.55 → 0.7로 얕게 해서 갑자기 사라지는 느낌을 없앴다.
- **측정(정점에서 −6dB → −30dB로 내려가는 시간, 길수록 완만)**: 불 220 → **304ms**, 물 258 → **322ms**, 대지 189 → **327ms**, 무속성 137 → **160ms**. 같은 총 길이에서 정점 근처 유지 시간은 줄고(대지 411 → 219ms) 공간감(0.3초 이후 에너지 비율)은 이전 수준을 유지한다.
- 페이드 시작을 너무 일찍(0.3) 잡으면 끊김은 더 줄지만 공간감이 크게 줄어(불 60% → 39%) 0.4로 타협했다. 바꾸려면 `ELEMENT[속성].fade`.

### 번개 소리 — 물 공격의 "아주르 썬더폴" 연출
- 물 속성으로 공격하면 번개 그림 연출("아주르 썬더폴")이 뜨는데, 이 연출 코드에는 원래 소리가 없었다. 예전에는 물 피격음에 섞여 있던 **폭발 샘플(천둥 같은 울림)** 이 번개 소리처럼 들렸다.
- 물이 불처럼 들리는 문제로 그 샘플을 뺐기 때문에, 번개 소리는 **연출 전용으로 분리**했다: 주문 팩의 번개 샘플을 **번개가 내리치는 순간이 시작 후 0.45초**에 오도록 앞을 잘라 정렬(`spellLightningCast`)해서, 연출이 뜰 때 차오르다가 타격 시점에 내리친다.
- 연출과 같은 시점(`registerChain`의 물 분기)에서 `playLightning()`을 호출한다. `?sfxpack=base`면 재생하지 않는다.
- **공간감을 만드는 처리는 넣지 않는다** (잔향 전송 0, 좌우 확장 없음): 원본 샘플 소리 하나만 낸다. 측정해 보니 이 처리를 빼도 거의 달라지지 않았는데(좌우 상관 0.84 → 0.87), 번개 샘플 자체에 번개 뒤 방이 울리는 잔향이 녹음되어 있기 때문이다. 이 울림을 줄이려면 꼬리 길이(`playLightning(pan, { cap })`)를 줄인다: 2.7초 → 꼬리 약 1.7초, 1.8초 → 약 1.3초, 1.2초 → 약 0.8초. 시험실에 세 가지 비교 버튼이 있다.
- 번개는 천둥처럼 **길게 울린다**: 꼬리 최대 2.7초(원본 약 3초), 실측 -30dB까지 약 1.8초(다른 피격음 0.3~1.1초). 조절은 `playLightning()`의 `cap`/`fade`.

### 연속 타격 (한 턴에 5번 안팎)
- 최근 **2.5초 안에 타격이 쌓일수록** 잔향과 꼬리를 줄입니다 (타격 1번당 −16%, 최소 45%).
- **새 타격이 들어올 때마다 이전 타격의 잔향을 잠깐 눌렀다가** 서서히 되돌립니다 (꼬리끼리 뭉치는 것 방지).
- 0.9초 간격 5연타 측정: 다음 타격 직전에 불·물·대지는 −37~−43dB로 잔향이 거의 사라지고, 바람·무속성은 완전히 끊깁니다.

### 평타 휘두르는 소리
평타 모션 6종마다 다른 소리가 납니다 (내려찍기=상승하는 바람, 박치기=낮은 쿵, 찌르기=짧은 두 번 틱, 회전=오르내리는 소용돌이, 곡선 접근=좌우로 지나가는 휙, 돌진=기본 휙). 짧은 공간(작은 방)을 쓰고 공격력과 무관하게 같은 세기입니다.

## 2. 평타 모션

| 모션 | 설명 | 주로 쓰는 속성 |
|---|---|---|
| 돌진 (lunge) | 기존 기본 동작: 물러났다가 돌진 | 무속성, 모두 소량 |
| 내려찍기 (slam) | 높이 뛰어올라 내리찍음 | 불 ★, 대지 |
| 박치기 (bash) | 한껏 웅크렸다가 묵직하게 들이받음 | 대지 ★, 불 |
| 찌르기 (jab) | 짧게 두 번 찌른 뒤 본 공격 | 바람 ★ |
| 회전 베기 (spin) | 회전하며 파고듦 | 바람, 물 |
| 곡선 접근 (swoop) | 호를 그리며 휘감아 접근 | 물 ★ |

- **공격력이 높을수록** 큰 동작(내려찍기·박치기)이 자주 나오고 움직임이 커집니다. 공격력이 낮으면 가벼운 찌르기가 늘어납니다.
- 같은 공격자는 **직전과 같은 동작을 연달아 하지 않습니다.**
- 타격(피해) 시점은 동작마다 다르며 모션의 접촉 지점에 맞춰집니다. 모든 동작은 900ms 이내에 끝납니다(전투 순서 간격이 900ms).
- "움직임 줄이기" 설정에서는 기본 돌진만 사용합니다.
- 공격 중에는 내 전장 칸의 잘림(`overflow:hidden`)을 풀어 카드가 칸 밖으로 나가도 잘리지 않게 했습니다.

## 5. 측정 도구 (듣지 않고 수치로 확인)

`python3 -I 12_tools/qa/measure-sfx.py` (서버 8765 필요)

| 옵션 | 내용 |
|---|---|
| (없음) | 속성×조합별 음량(rms), 피크, 꼬리 끊김(cut), 꼬리(tail30), 잔향 비율(late), 좌우 상관(corr), 무게중심(centroid) |
| `--wav 폴더` | 조합별 WAV 저장 — 귀로 직접 들어 볼 때 |
| `--burst` | 0.9초 간격 5연타 시 잔향이 얼마나 정리되는지 |
| `--calibrate` | 조합별 음량 균형을 목표에 맞춰 `TRIM`에 기록 (페이드·공간 설정을 바꾸면 반드시 다시 실행, 끝나면 `npm run build:runtime`) |

- 음량 목표는 사람 귀가 민감한 고음(3~5kHz)이 많은 소리(바람 −4dB, 무속성 −1dB)를 낮추고, 낮고 묵직해야 하는 대지는 +7dB 키웁니다. **불은 처음 방식의 원본 폭발음(이전 방식 볼륨 RMS 약 −18dB)보다 조금 작은 −20.5dB**로 잡았습니다 (`TARGET_OFFSET`).
- **안전 리미터**: 효과음 버스(`sfxBus`) 끝에 리미터(−6dB 임계, 비율 20:1)를 두어, 효과음 슬라이더를 크게 올려도(특히 대지) 소리가 찌그러지지 않게 했습니다. 효과음 슬라이더를 최대로 올려도 피크가 −9dBFS 안쪽이라 찌그러지지 않습니다.
