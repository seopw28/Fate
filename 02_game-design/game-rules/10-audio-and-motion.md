# 10. 효과음과 평타 모션

> 피해 소리가 "픽! 픽!"으로 단조롭고 평타 모션이 전원 똑같다는 피드백에서 출발했습니다 (TEAM_REVIEW, 2026-11-01).
> 코드: `05_game-client/battle/sfx-variety.js`, `attack-motions.js` (빌드 시 `dist/runtime/`으로 복사)

## 1. 피격 효과음

### 구성: 샘플 + 합성음 레이어

한 번 칠 때마다 **① 녹음 샘플(Kenney Impact Sounds)** 과 **② 코드로 합성한 소리**를 겹쳐 재생합니다. 샘플이 아직 로드되지 않았거나 실패해도 합성음만으로 소리가 나고, 음소거면 아무것도 하지 않습니다.

| 속성 | 샘플 느낌 | 합성음 후보 (강도에 따라 1~2개) |
|---|---|---|
| 불 | 둔탁한 타격·연질 쿵 (+강타 시 폭발) | 타닥임(crackle), 저음 쿵(thump), 치직(sizzle) |
| 물 | 유리·종 (맑고 깨지는 소리) | 물방울(bubbles), 물보라(splash), 똑(drip) |
| 바람 | 칼날 + 가벼운 금속 | 휙(whoosh), 날카로운 새소리(chirp), 베기(slice) |
| 대지 | 나무·광석·묵직한 울림 | 우르릉(rumble), 돌 갈라짐(crack), 쿵(thud) |
| 무속성 | 금속·판 | 종 울림(ring), 챙(clink), 쇠 울림(clang) |

### 강도 단계 (피해량 기준)

| 단계 | 피해 | 소리 |
|---|---|---|
| light | 3 이하 | 가볍고 높은 음, 합성음 1개 |
| medium | 4~6 | 기본 |
| heavy | 7~10 | 낮고 묵직, 합성음 2개 |
| massive | 11 이상 | 가장 낮고 큼, 샘플 3개 겹침 (폭발/종 포함) |

### 변주 장치 (같은 소리가 반복되지 않게)
- 같은 속성·강도에서도 **샘플 조합 후보가 2~3개**이고, **직전에 쓴 조합은 제외**하고 고릅니다. 합성음도 같은 방식입니다.
- 샘플은 종류마다 5개 변형이 있고 직전과 다른 것을 고릅니다.
- 매번 음높이(±6%), 볼륨(±12%), 겹치는 타이밍(최대 20ms 어긋남)이 조금씩 달라집니다.
- **좌우 위치(pan)**: 맞는 대상이 화면 왼쪽이면 왼쪽에서, 오른쪽이면 오른쪽에서 들립니다.

### 평타 휘두르는 소리
평타 모션 6종마다 다른 소리가 납니다 (내려찍기=상승하는 바람, 박치기=낮은 쿵, 찌르기=짧은 두 번 틱, 회전=오르내리는 소용돌이, 곡선 접근=좌우로 지나가는 휙, 돌진=기본 휙).

## 2. 평타 모션

| 모션 | 설명 | 주로 쓰는 속성 |
|---|---|---|
| 돌진 (lunge) | 기존 기본 동작: 물러났다가 돌진 | 무속성, 모두 소량 |
| 내려찍기 (slam) | 높이 뛰어올라 내리찍음 | 불 ★, 대지 |
| 박치기 (bash) | 한껏 웅크렸다가 묵직하게 들이받음 | 대지 ★, 불 |
| 찌르기 (jab) | 짧게 두 번 찌른 뒤 본 공격 | 바람 ★ |
| 회전 베기 (spin) | 회전하며 파고듦 | 바람, 물 |
| 곡선 접근 (swoop) | 호를 그리며 휘감아 접근 | 물 ★ |

- **공격력이 높을수록** 큰 동작(내려찍기·박치기)이 자주 나오고 움직임이 커집니다. 공격력이 낮으면 가벼운 찌르기가 늘어납니다.
- 같은 공격자는 **직전과 같은 동작을 연달아 하지 않습니다.**
- 타격(피해) 시점은 동작마다 다르며 모션의 접촉 지점에 맞춰집니다. 모든 동작은 900ms 이내에 끝납니다(전투 순서 간격이 900ms).
- "움직임 줄이기" 설정에서는 기본 돌진만 사용합니다.
- 공격 중에는 내 전장 칸의 잘림(`overflow:hidden`)을 풀어 카드가 칸 밖으로 나가도 잘리지 않게 했습니다.

## 3. 음원과 라이선스

| 항목 | 내용 |
|---|---|
| 음원 | Kenney **Impact Sounds** 1.0 — 충격음 105개(걷는 소리 제외), 모노 mp3로 변환 (총 약 310KB) |
| 라이선스 | **CC0** (개인·교육·상업 프로젝트 모두 자유, 출처 표기는 선택). 안내문이 `dist/assets/audio/sfx/LICENSE-kenney-impact-sounds.txt`에 함께 있음 |
| 출처 | https://kenney.nl/assets/impact-sounds |
| 기존 음원 | `sword-slash.mp3`, `explosion-impact.mp3`, `metal-impact.mp3` (바람·폭발 조합에 재사용) |
| 변환 | `python3 -I 12_tools/asset-pipeline/build-sfx.py <풀어둔_폴더>` — 무음 제거, 피크 -3dB 정규화, 1.2초 이내 페이드. 원본 zip은 저장소에 넣지 않음 |
| 로딩 | 첫 클릭/키 입력 때 한 번에 불러옴(브라우저 자동재생 정책). 로딩 전에는 합성음만 |
| 추가 후보 | 속성별 풍부함이 더 필요하면 "Elemental Forces Sound Pack"(CC0, $2) 검토 → [09](09-decisions-and-open-issues.md) |
