# 02. 시작 세팅, 턴 흐름, 전투

## 1. 전투 시작 세팅

| 항목 | 내 쪽 | 상대 쪽 |
|---|---|---|
| 영웅 체력 | 100 | 100 |
| 시작 마나 | 3 (최대 3) | 내 최대 마나와 동일하게 따라감 → [07](07-opponent-ai.md) |
| 초기 전장 | **0장 (빈 전장)** | 0장 |
| 손패 | 5장 (아래 구성) | 5장 |
| 덱 | 60장 | 60장 |
| 선공 | 라운드마다 아래 "선공권" 우선순위로 결정 | |

- **초기 전장 장수**는 `OPENING_FIELD_SIZE`(기본 0)로 조절합니다. 현재는 "빈 전장에서 낮은 비용 카드부터 직접 세팅"하는 방침입니다. 2로 올리면 양쪽 덱에서 **시작 마나(3) 이하 비용** 카드 2장씩 깔리고, 상대 전력(공격력+체력 합)은 내 전력을 넘지 않게 조정됩니다.
- **내 시작 손패 5장 구성**: 편성한 60장 덱에서 뽑으며 비용 3 이하 챔프 2장과 함정이 아닌 비용 3 이하 마법 1장을 보장합니다. 해당 마법이 덱에 없으면 나머지 카드로 채웁니다. 주소에 `?fixedStarter`를 붙이면 `battle-starter.json`에서 앞의 5장으로 시작합니다(QA용).
- 성격 오라는 시작 손패가 정해진 **뒤에** 고릅니다. 불 오라의 열정 특성은 이후 내 챔프가 기본 공격할 때마다 발동 여부를 판정합니다.

### 선공권 (라운드마다 누가 먼저 행동하는가)

| 순서 | 조건 | 선공 |
|---|---|---|
| ① | 영웅 체력이 서로 다르면 | **체력이 더 낮은 쪽** |
| ② | 체력이 같고 전장 카드 수가 다르면 | **전장 카드가 더 적은 쪽** |
| ③ | 체력과 전장이 모두 같으면 | **무작위** |

- **밀리는 쪽이 먼저 행동**해서 따라잡을 기회를 얻는 장치입니다.
- 라운드가 시작될 때 필드 중앙에 **이유와 결론을 한 문장으로** 알려 줍니다. 예: `상대의 체력이 더 높으니 나의 선공입니다.` / `상대의 체력이 더 낮으니 상대의 선공입니다.` / `체력이 같고 내 전장 카드가 더 적으니 나의 선공입니다.` 단어가 차례로 떠오르고 결론이 빛나며 맺히며, 아래에 양쪽 체력(또는 전장 카드 수)이 작게 표시됩니다. 약 2.9초. 전투 로그에도 이유가 남습니다.
- **상대가 선공이면** 상대가 먼저 소환하고 공격한 뒤에 내 준비 단계가 시작됩니다. 내가 선공이면 아래 흐름 그대로 내 행동 → 내 전투 → 상대 턴입니다.

## 2. 한 라운드의 흐름 (내가 선공일 때)

| 단계 | 일어나는 일 |
|---|---|
| ① 내 턴 시작 | 턴 번호 +1, 최대 마나 +1(최대 10), 마나 전부 회복, 혈마나/드로우 횟수 초기화, **카드 1장 자동 드로우**, 내 챔프 행동 가능 상태로 복귀, 함정 "필드 상태" 검사 |
| ② 준비(내 행동) | 카드 소환, 마법 발동(손패 더블클릭), 함정 세팅, 궁극기 장착·발동(장착한 턴에는 발동 불가), 카드 뽑기, 전장 순서 변경(드래그) |
| ③ 턴 종료 (Enter) | 내 챔프가 **자동으로 전투** (아래 3절) |
| ④ 화상 정산 | 화상이 걸린 모든 유닛이 화상 수치만큼 피해를 받고 화상 해제 |
| ⑤ 상대 턴 | 상대 마나 갱신 → 1장 드로우 → 소환 → 상대 챔프 전부 공격 |
| ⑥ 다음 라운드 | ①로 돌아감 |

- 턴 종료 버튼은 준비 단계에서만 눌립니다. 전투/상대 턴 중에는 비활성입니다.
- 새 턴 시작 시 손패 탭은 자동으로 "캐릭터 카드" 탭으로 돌아갑니다.

## 3. 내 챔프의 전투 (턴 종료 시 자동)

1. 행동 가능한(공격 완료·소환 직후가 아닌) 챔프가 **전장 왼쪽부터 순서대로** 공격합니다.
2. 각 챔프의 대상은 **상대 전장의 맨 왼쪽 챔프**입니다. 상대 전장이 비어 있으면 상대 영웅을 칩니다.
3. 카드와 카드가 교전하면 **수치상 양쪽이 상대 카드의 공격력만큼 피해**를 받지만, 화면 연출과 실제 피해 반영은 공격과 반격 순서로 진행합니다. 금속 오라·함정 등의 추가 효과는 기본 반격이 끝난 뒤 별도 순서로 발동합니다.
   - 양쪽 공격력은 교전 시작 순간 확정합니다. 첫 타격이 치명적이어도 방어 카드는 확정된 공격력으로 기본 반격한 뒤 사망합니다. 반격을 막으려면 추후 `선제공격`처럼 명시적인 예외 효과가 필요합니다.
   - 화면에서는 공격자의 타격이 끝난 뒤 방어 카드가 공격자에게 맞받아치는 이동·타격 연출을 순차 재생합니다. 공격자는 이 피격 연출과 피해 숫자가 보인 뒤 사망 처리되어, 원인 없이 사라져 보이지 않아야 합니다.
   - 타격 후 약 1초의 확인 시간을 두고 반격하며, 추가 오라 반응과 카드 후속 효과까지 순서대로 보여 줍니다. 고정된 공격 시작 간격은 사용하지 않습니다. 각 교전의 공격·반격·후속 효과 연출이 실제로 끝난 뒤 **0.3초**의 판독 여유만 두고 다음 챔프가 공격합니다.
   - 영웅 직접 공격은 카드 피격용 긴 이펙트 꼬리를 기다리지 않고 짧은 완료 시간을 사용합니다. 마지막 교전은 0.3초의 카드 간 여유도 추가하지 않고 바로 다음 전투 단계나 턴으로 넘어갑니다.
   - 카드 피격은 핵심 피해 숫자와 타격 반응이 끝나는 시점까지만 전투 큐를 점유합니다. 희미한 잔여 파티클은 다음 행동과 겹쳐 사라집니다. 각성 배너가 실제로 표시되지 않는 경우에는 배너용 대기 시간을 등록하지 않습니다.
   - 전역 도발 카드가 치명상을 받으면 체력 0을 즉시 표시하되, 기본 반격과 사망 제거가 끝날 때까지 다음 공격을 시작하지 않습니다. 카드가 제거된 뒤에만 도발이 해제됩니다.
   - 공격력 0은 유효한 수치입니다. 카드 교전과 영웅 직접 공격 모두 최소 피해로 올려 계산하지 않으며 실제 피해 0으로 처리합니다.
   - 마지막 정산 뒤 단계 전환은 약 0.27초, 상대 선공 준비는 약 0.54초만 사용합니다. 선공 안내는 진행을 막는 별도 대기 화면이 아니라 다음 행동과 함께 표시합니다.
4. 수동 공격도 가능합니다: 내 챔프를 선택 → 상대 카드를 클릭하면 맨 왼쪽 챔프가 대상으로 자동 지정됩니다.
5. 상대 영웅을 직접 클릭해도 상대 전장에 생존 챔프가 있으면 영웅 피해로 우회하지 않습니다. 도발 챔프가 있으면 도발 챔프가, 아니면 맨 왼쪽 챔프가 공격을 대신 받습니다.

> 소환한 턴의 챔프는 "행동 완료" 상태라 그 턴에는 공격하지 않습니다. 예외: 게일 러시·디멘션 이지스 같은 즉시 행동 효과, 궁극기 소진자(내려놓은 즉시 공격).

## 4. 상대 챔프의 전투 (상대 턴)

- **카드 배치 템포**: 상대가 한 턴에 여러 장을 내더라도 **한 장씩 약 0.34초 간격**을 두고 순서대로 내려놓습니다. 같은 프레임에 여러 장이 한꺼번에 나타나면 사람이 두는 느낌이 사라지므로 금지합니다. 빈 필드를 막기 위한 전개 우선 소환이 먼저 일어난 경우에도 그 다음 카드까지 같은 간격을 둡니다. 간격은 전투 속도 배율(`COMBAT_TIME_SCALE`)을 함께 적용합니다.
- 상대 챔프도 플레이어와 동일하게 **소환한 턴에는 공격하지 못하며, 다음 상대 턴부터 공격**합니다. 예외는 게일 러시·디멘션 이지스처럼 즉시 행동을 명시한 효과입니다.
- 대상은 기본적으로 **내 전장의 맨 왼쪽 챔프**이며, 내 전장이 비어 있으면 내 영웅입니다. 단, 궁극기 소진자가 살아 있으면(소진자 자신은 상대 소진자가 없는 한 챔프가 있어도 상대 영웅을 우선 공격) 위치와 무관하게 모든 상대 기본 공격이 그 카드를 먼저 공격합니다.
- 그래서 내가 **전장 순서를 드래그로 바꿔** 누구를 앞에 세울지 정하는 것이 방어 전략의 핵심입니다. (준비 단계에서만 변경 가능)

## 5. 피해 계산

```
최종 공격력 = 카드 기본 공격력 + 등급 보너스(C0/B1/A2) + 전장 보너스(공명 +1, 조화 +1)
```

- **카드 대 카드 기본 교전 피해**: `상대의 최종 공격력`. 공격자와 방어자가 각각 이 계산으로 피해를 받습니다.
- **연출 원칙**: 공격자의 타격 후 방어자의 반격을 순차 시각화합니다. 방어자의 타격 시점에 공격자가 교환 피해를 받고, 판정상 보호막·피해 감소·사망·묘지 이동도 그 연출 뒤 적용됩니다.
- 교환 피해는 공격 카드가 사망 예정 상태가 되었더라도 생략하지 않습니다. 공격 카드 위에 `교환 −N`을 표시하며, 보호막이 막으면 `교환 0 · 보호막`을 표시합니다.
- 영웅 직접 공격, 마법, 궁극기, 화상 등은 상호 피해를 만들지 않으며 각 효과에 적힌 피해를 그대로 적용합니다.

| 전장 보너스 | 조건 (같은 편 전장 기준) |
|---|---|
| 공명 +1 | 자신과 **같은 오라**(무오라 제외) 챔프가 2장 이상 |
| 조화 +1 | 서로 다른 오라(무오라 제외)이 3종 이상 |

- 보호막이 있으면 한 번의 피해를 통째로 막고 사라집니다.
- 체력이 0이 되면 쓰러집니다 → 내 챔프는 묘지로 기록되어 부활 효과의 대상이 됩니다.
- **평타 연출 원칙**: 기본 공격은 **전면 컷인을 띄우지 않습니다**. 오라 연쇄가 폐지되어 보너스가 0인데 컷인만 남아 있어, 기본 공격마다 화면을 덮으면서 정작 의미 있는 교전 연출(궤적·착탄)을 가렸습니다. 전면 컷인 7종(실피드 템페스트·아주르 썬더폴·이그니스 메테오·니플헤임 노바·가이아 브레이커·볼트 레퀴엠·페이트 이클립스)은 **광역 마법카드의 발동 연출로 이관**했습니다. 속성 고유 소리는 평타에 남기되 컷인용 세기 그대로면 과하므로 약화합니다(칼바람 3연타→1회·45%, 번개 50%).
- **평타 연출 3레이어**: 전면 컷인을 걷어낸 자리를 교전 연출 자체로 메웁니다. ① **궤적** — 피해량에 비례해 두께(3~8px)·발광·속도가 변하고 잔상이 따라붙습니다. 반격은 끊긴 질감으로 그려 누가 쳤는지 즉시 구분합니다. 대상 체력을 넘기는 치명타는 흰 심지가 굵게 박히고 더 오래 남습니다. ② **착탄** — 타격 지점에 속성색 섬광과 8방향 파편이 터지며, 피해량에 따라 크기가 커집니다. ③ **반동** — 때린 쪽도 피해량에 비례한 반작용으로 밀립니다. 수치 교환이 화면에서 바로 읽히게 하는 것이 목적이며, 평타가 전투의 주연출입니다.
- **폐지된 규칙** (코드에 흔적이 남아 있으니 되살리지 말 것): 오라 상성(유리/불리 배율), 확률 방어(피해 반감), 오라 연쇄 보너스. 오라는 지금 **공명/조화 보너스와 연출**에만 쓰입니다.

## 6. 상태이상·표식

| 상태 | 효과 | 해제 |
|---|---|---|
| 화상 N | 부여 즉시 카드 하단에 붉은 불꽃이 지속 표시되고, 내 턴 전투가 끝난 직후 N 피해(보호막이 막음) | 피해를 준 직후 해제. 정화 시 즉시 표시와 함께 해제 |
| 동결 | 그 챔프가 **다음 공격을 한 번 건너뜀** (푸른 맥동으로 표시) | 건너뛴 직후 |
| 행동 불가(`exhausted`) | 이번 턴 공격 완료/소환 직후. 회색 처리 | 내 다음 턴 시작 |
| 보호막 | 다음 피해 1회 무효 | 사용 즉시 |
| 불가침(무적) | 소환한 턴(상대 턴 포함) 모든 피해 무효. 황금빛 맥동 | 내 다음 턴 시작 |
| (도발) | 코드에 판정은 남아 있으나 **현재 이 상태를 켜 주는 카드/규칙이 없음** (비활성) | - |
| 폭발 표식 | 같은 적에게 3개 쌓이면 4 피해로 폭발 | 폭발 시 |
| 충격 저장 | 피해를 받을 때마다 다음 공격 +2(최대 +6) | 공격 후 |

## 7. 드로우와 손패

- 내 턴 시작 시 1장 자동 드로우 (복수자가 두 번째로 등장한 뒤부터는 1장 더). 추가로 "카드 뽑기" 행동을 쓸 수 있습니다.
- **카드 뽑기 비용**: 그 턴의 n번째 뽑기는 마나 2ⁿ (2, 4, 8, 16, …, `DRAW_BASE_COST = 2`). 마나가 모자라면 혈마나로 대신합니다.
- 손패는 최대 8장. 가득 차면 뽑기가 막힙니다. 덱이 비면 드로우만 생략하고 손패와 전장으로 계속 싸웁니다.
- 모든 드로우는 편성한 60장 덱의 남은 카드에서 진행하며, 덱을 소진할 때까지 챔프·마법·함정을 뽑을 수 있습니다. 덱에 챔프가 없을 때 `카드 뽑기`를 누르면 체력 10을 내고 묘지 챔프를 덱에 섞을지 예/아니오로 묻습니다([04](04-ultimate-and-comeback.md)).

## 8. 혈마나 (체력으로 내는 마나)

- **3턴부터** 사용할 수 있습니다.
- **배틀 첫 혈마나 1번**은 모자란 마나 1당 영웅 체력 1을 지불합니다(마나와 같은 양, `BLOOD_MANA_FIRST_RATE = 1`). 마나 칸에 `혈마나 1 = ♥ 1 · 첫 1회`로 표시합니다.
- **두 번째부터**는 모자란 마나 1당 영웅 체력 `2 + (이번 턴 이미 쓴 혈마나 횟수)`를 지불합니다(`BLOOD_MANA_BASE_RATE = 2`, `BLOOD_MANA_RATE_STEP = 1`). 배틀 첫 사용은 이 횟수에 넣지 않으므로, 두 번째 사용은 같은 턴이어도 마나 3이 모자라면 체력 6입니다. 같은 턴에 더 쓸수록 비싸집니다.
- **2026-11-08 변경**: 마나 1당 체력 4는 손해가 커서 거의 쓰지 않았습니다. 첫 1번은 마나와 같은 양, 이후는 2로 낮췄습니다. 비교 기준으로 강철 파쇄탄은 마나 2로 상대 영웅에 5 피해(마나 1당 2.5)를 줍니다.
- 남는 마나를 먼저 모두 쓰고 부족분만 체력으로 냅니다. 지불 후 영웅 체력이 1 이상이어야 합니다.
- 혈마나로 체력이 줄면 오라 각성 조건(체력 85 이하)에 가까워지는 전략적 효과가 있습니다.
