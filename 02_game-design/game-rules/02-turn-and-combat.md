# 02. 시작 세팅, 턴 흐름, 전투

## 1. 전투 시작 세팅

| 항목 | 내 쪽 | 상대 쪽 |
|---|---|---|
| 영웅 체력 | 100 | 100 |
| 시작 마나 | 3 (최대 3) | 내 최대 마나와 동일하게 따라감 → [07](07-opponent-ai.md) |
| 초기 전장 | **0장 (빈 전장)** | 0장 |
| 손패 | 7장 (아래 구성) | 5장 |
| 덱 | 60장 | 60장 |
| 선공 | 라운드마다 아래 "선공권" 우선순위로 결정 | |

- **초기 전장 장수**는 `OPENING_FIELD_SIZE`(기본 0)로 조절합니다. 현재는 "빈 전장에서 낮은 비용 카드부터 직접 세팅"하는 방침입니다. 2로 올리면 양쪽 덱에서 **시작 마나(3) 이하 비용** 카드 2장씩 깔리고, 상대 전력(공격력+체력 합)은 내 전력을 넘지 않게 조정됩니다.
- **내 시작 손패 7장 구성**: 편성한 60장 덱에서 뽑으며 비용 3 이하 챔프 2장을 보장합니다. 주소에 `?fixedStarter`를 붙이면 `battle-starter.json`에서 앞의 7장으로 시작합니다(QA용).
- 수호신은 시작 손패가 정해진 **뒤에** 고릅니다. 그래서 제우스(S급 강화)는 시작 손패에 적용되지 않습니다.

### 선공권 (라운드마다 누가 먼저 행동하는가)

| 순서 | 조건 | 선공 |
|---|---|---|
| ① | 영웅 체력이 서로 다르면 | **체력이 더 낮은 쪽** |
| ② | 체력이 같고 전장 카드 수가 다르면 | **전장 카드가 더 적은 쪽** |
| ③ | 체력과 전장이 같고 티어가 다르면 | **티어가 더 낮은 쪽** |
| ④ | 체력·전장·티어가 모두 같으면 | **무작위** |

- **밀리는 쪽이 먼저 행동**해서 따라잡을 기회를 얻는 장치입니다 (역전 돌진과 같은 취지).
- 라운드가 시작될 때 필드 중앙에 **이유와 결론을 한 문장으로** 알려 줍니다. 예: `상대의 체력이 더 높으니 나의 선공입니다.` / `상대의 체력이 더 낮으니 상대의 선공입니다.` / `체력이 같고 내 전장 카드가 더 적으니 나의 선공입니다.` 단어가 차례로 떠오르고 결론이 빛나며 맺히며, 아래에 양쪽 체력(또는 전장 카드 수)이 작게 표시됩니다. 약 2.9초. 전투 로그에도 이유가 남습니다.
- **상대가 선공이면** 상대가 먼저 소환하고 공격한 뒤에 내 준비 단계가 시작됩니다. 내가 선공이면 아래 흐름 그대로 내 행동 → 내 전투 → 상대 턴입니다.

## 2. 한 라운드의 흐름 (내가 선공일 때)

| 단계 | 일어나는 일 |
|---|---|
| ① 내 턴 시작 | 턴 번호 +1, 최대 마나 +1(최대 10), 마나 전부 회복, 혈마나/드로우 횟수 초기화, **카드 1장 자동 드로우**, 내 챔프 행동 가능 상태로 복귀, 함정 "필드 상태" 검사, **세트해 둔 마법 발동** |
| ② 준비(내 행동) | 카드 소환, 마법/함정 세팅, 궁극기 장착·발동, 카드 뽑기, 전장 순서 변경(드래그) |
| ③ 턴 종료 (Enter) | 내 챔프가 **자동으로 전투** (아래 3절) |
| ④ 화상 정산 | 화상이 걸린 모든 유닛이 화상 수치만큼 피해를 받고 화상 해제 |
| ⑤ 상대 턴 | 상대 마나 갱신 → 1장 드로우 → 소환 → 상대 챔프 전부 공격 |
| ⑥ 다음 라운드 | ①로 돌아감 |

- 턴 종료 버튼은 준비 단계에서만 눌립니다. 전투/상대 턴 중에는 비활성입니다.
- 새 턴 시작 시 손패 탭은 자동으로 "캐릭터 카드" 탭으로 돌아갑니다.

## 3. 내 챔프의 전투 (턴 종료 시 자동)

1. 행동 가능한(공격 완료·소환 직후가 아닌) 챔프가 **전장 왼쪽부터 순서대로** 공격합니다.
2. 각 챔프의 대상은 **상대 전장의 맨 왼쪽 챔프**입니다. 상대 전장이 비어 있으면 상대 영웅을 칩니다.
3. 공격은 일방적입니다. **맞은 쪽이 반격하지 않습니다** (반격은 아테나 수호신·함정 등 특수 효과로만 발생).
4. 수동 공격도 가능합니다: 내 챔프를 선택 → 상대 카드를 클릭하면 맨 왼쪽 챔프가 대상으로 자동 지정됩니다.
5. ⚠ **현재 구현의 허점**: 내 챔프를 선택하고 **상대 영웅을 직접 클릭하면, 상대 챔프가 전장에 있어도 영웅에게 피해가 들어갑니다**(시험: 상대 챔프 1장이 있는 상태에서 100 → 96). 의도된 규칙인지 확인이 필요합니다 → [09](09-decisions-and-open-issues.md).

> 소환한 턴의 챔프는 "행동 완료" 상태라 그 턴에는 공격하지 않습니다. 예외: 게일 러시·디멘션 이지스 같은 즉시 행동 효과, 역전 돌진([04](04-ultimate-and-comeback.md)), 천공 해방 궁극기.

## 4. 상대 챔프의 전투 (상대 턴)

- 상대 챔프는 **소환한 턴에도 즉시 공격**합니다 (내 챔프와의 비대칭).
- 대상은 **내 전장의 맨 왼쪽 챔프**이며, 내 전장이 비어 있으면 내 영웅입니다.
- 그래서 내가 **전장 순서를 드래그로 바꿔** 누구를 앞에 세울지 정하는 것이 방어 전략의 핵심입니다. (준비 단계에서만 변경 가능)

## 5. 피해 계산

```
최종 공격력 = 카드 기본 공격력 + 등급 보너스(C0/B1/A2/S3) + 전장 보너스(공명 +1, 조화 +1)
```

| 전장 보너스 | 조건 (같은 편 전장 기준) |
|---|---|
| 공명 +1 | 자신과 **같은 속성**(무속성 제외) 챔프가 2장 이상 |
| 조화 +1 | 서로 다른 속성(무속성 제외)이 3종 이상 |

- 보호막이 있으면 한 번의 피해를 통째로 막고 사라집니다.
- 체력이 0이 되면 쓰러집니다 → 내 챔프는 묘지로 기록되어 부활 효과의 대상이 됩니다.
- **폐지된 규칙** (코드에 흔적이 남아 있으니 되살리지 말 것): 속성 상성(유리/불리 배율), 확률 방어(피해 반감), 속성 연쇄 보너스. 속성은 지금 **공명/조화 보너스와 연출**에만 쓰입니다.

## 6. 상태이상·표식

| 상태 | 효과 | 해제 |
|---|---|---|
| 화상 N | 내 턴 전투가 끝난 직후 N 피해(보호막이 막음) | 피해를 준 직후 해제 |
| 동결 | 그 챔프가 **다음 공격을 한 번 건너뜀** (푸른 맥동으로 표시) | 건너뛴 직후 |
| 행동 불가(`exhausted`) | 이번 턴 공격 완료/소환 직후. 회색 처리 | 내 다음 턴 시작 |
| 보호막 | 다음 피해 1회 무효 | 사용 즉시 |
| 불가침(무적) | 소환한 턴(상대 턴 포함) 모든 피해 무효. 황금빛 맥동 | 내 다음 턴 시작 |
| (도발) | 코드에 판정은 남아 있으나 **현재 이 상태를 켜 주는 카드/규칙이 없음** (비활성) | - |
| 폭발 표식 | 같은 적에게 3개 쌓이면 4 피해로 폭발 | 폭발 시 |
| 충격 저장 | 피해를 받을 때마다 다음 공격 +2(최대 +6) | 공격 후 |

## 7. 드로우와 손패

- 내 턴 시작 시 1장 자동 드로우 (최후의 발악 상태면 1장 더). 추가로 "카드 뽑기" 행동을 쓸 수 있습니다.
- **카드 뽑기 비용**: 그 턴의 n번째 뽑기는 마나 n (1, 2, 3, …). 마나가 모자라면 혈마나로 대신합니다.
- 손패는 최대 8장. 가득 차면 뽑기가 막힙니다. 덱이 비면 드로우만 생략하고 손패와 전장으로 계속 싸웁니다.
- 모든 드로우는 편성한 60장 덱의 남은 카드에서 진행하며, 덱을 소진할 때까지 챔프·마법·함정을 뽑을 수 있습니다.

## 8. 혈마나 (체력으로 내는 마나)

- **3턴부터** 사용할 수 있습니다.
- 모자란 마나 1당 영웅 체력 `4 + (이번 턴 이미 쓴 혈마나 횟수)`를 지불합니다. 같은 턴에 쓸수록 비싸집니다.
- 남는 마나를 먼저 모두 쓰고 부족분만 체력으로 냅니다. 지불 후 영웅 체력이 1 이상이어야 합니다.
- 혈마나로 체력이 줄면 [역전 돌진/최후의 발악](04-ultimate-and-comeback.md) 조건에 가까워지는 전략적 효과가 있습니다.
