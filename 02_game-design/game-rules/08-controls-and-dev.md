# 08. 조작, 테스트 옵션, 개발·QA

## 1. 조작 (플레이어)

| 입력 | 동작 |
|---|---|
| 카드 클릭 → **다시 클릭** | 카드 사용 (하수인 소환 / 마법·함정 세팅). 첫 클릭은 선택 |
| 카드 드래그 → 필드 | 소환 (선택 후 확정과 동일) |
| 카드 드래그 → 궁극기 패널 | 궁극기로 장착 |
| 마법 슬롯 더블클릭 / 손패로 드래그 | 세팅 취소(턴 종료 전, 비용 환불) |
| 내 전장 카드 드래그 | **공격받는 순서 변경** (준비 단계에서만) |
| 내 하수인 선택 → 상대 카드 클릭 | 수동 공격 (대상은 항상 상대 맨 왼쪽) |
| **스페이스 바** | 손패 탭 전환 (캐릭터 ↔ 마법카드) |
| **Enter** | 턴 종료 (준비 단계에서만) |
| 기권 버튼 → 한 번 더 | 기권 (패배 처리, 보상 없음) |

- 단축키는 입력창에 포커스가 있을 때, 카드 소환/덱 편집 창·결과 화면이 열려 있을 때, Ctrl/Alt/Shift/Cmd 조합일 때, 키를 계속 누르고 있을 때는 무시됩니다.
- 새 턴이 시작되면 손패는 자동으로 캐릭터 탭으로 돌아옵니다.

## 2. 테스트용 주소 옵션

`http://localhost:8765/index.html` 뒤에 붙입니다. 여러 개는 `&`로 연결합니다.

| 옵션 | 효과 |
|---|---|
| `?skipIntro` | 전투 시작 연출 생략 (성격 오라 선택 화면은 그대로 표시) |
| `?crackers=10000` | 보유 크래커를 그 값으로 맞추고 저장. 적용 후 주소에서 옵션이 사라져 새로고침해도 다시 덮어쓰지 않음. **개발 환경 전용** |
| `?tab=spell` | 손패를 마법카드 탭으로 시작 |
| `?fixedStarter` | 시작 손패를 `battle-starter.json`의 앞 5장으로 고정 (재현용) |
| `?seed=문자열` | 덱 셔플 시드 고정 (결정적 재현용) |

> **개발 환경 전용** 옵션(`?crackers`, `?guardian`)은 주소의 호스트가 `localhost`, `127.0.0.1`, `[::1]`, 또는 `file://`일 때만 동작합니다(`DEV_MODE`). 배포 주소에서는 무시되어 재화를 만들거나 성격 오라를 공짜로 받는 우회로가 막혀 있습니다.
> 빈 전장으로 시작하는 현재 방침 때문에 `skipIntro` 사용 시에도 초기 전장은 비어 있습니다.

## 3. 로컬 실행

```bash
cd dist && python3 -m http.server 8765      # http://localhost:8765/index.html
```

### ngrok 외부 공개

공식 Node SDK를 사용하므로 별도 ngrok CLI가 필요하지 않습니다. 인증 토큰은 저장소나 `.env`에 커밋하지 않고 현재 터미널 환경변수로만 전달합니다.

```bash
export NGROK_AUTHTOKEN="ngrok 대시보드에서 복사한 토큰"
npm run ngrok
```

- 기본 로컬 주소: `http://127.0.0.1:8080`
- 기본 공개 주소: `https://flagstick-cubical-pungent.ngrok-free.dev`
- 다른 고정 도메인이나 포트는 `NGROK_DOMAIN`, `FATE_PORT` 환경변수로 덮어쓸 수 있습니다.
- 개발 환경에서는 `?difficulty=normal|nightmare|hell`로 컴퓨터 난이도 선택 화면을 건너뛸 수 있습니다. `?guardian=...`과 함께 쓰면 난이도와 오라를 모두 고정해 재현할 수 있습니다.
- 실행을 종료하면 공개 연결도 함께 닫힙니다.

## 4. 개발·QA 명령 (프로젝트 루트에서)

| 명령 | 용도 |
|---|---|
| `npm run build:runtime` | 카드 JSON → `dist/runtime/cards.js` 생성 (카드 데이터 수정 후 필수) |
| `npm run ngrok` | 게임 정적 서버(8080)와 ngrok 고정 도메인 터널을 함께 실행 |
| `npm run validate:cards` | 카드 데이터 검증 (허용되지 않은 효과 ID, 스타터 8장 등) |
| `npm test` | 카드 검증 + 효과 검증 + 엔진 + 플랫폼 + UI 계약 테스트 |
| `npm run qa:overflow` | **UI 글자 넘침·줄바꿈 이상 검사**. 내 `dist`를 직접 띄워 검사한다. `OK: 넘침·줄바꿈 이상 없음`이어야 통과. `npm test`에 포함 |
| `npm run qa:alignment` | **효과 위치 검사**. 소환 마법진·타격·라벨 등이 대상 카드 중심에서 벗어나지 않는지 잰다. `npm test`에 포함 (2026-11-08) |
| `node 09_balance-lab/match-simulator/guardian-balance.mjs --games 20000` | 성격 오라 밸런스 시뮬레이션 |

## 5. 개발 규칙 (루트 `CLAUDE.md` 요약)

- **UI 글자 넘침 금지**: 글자가 버튼·패널·카드 밖으로 나가거나 잘리면 안 됩니다. 폰트가 지마켓산스(폭이 넓음)라 특히 주의.
  - UI 문구·폰트·레이아웃을 건드렸으면 완료 보고 전에 `npm run qa:overflow` 통과 필수.
  - 버튼에 `white-space:nowrap` 금지, 고정 폭 상자는 가장 긴 문구 상태로 확인.
  - 동적으로 바뀌는 문구는 `12_tools/qa/check-text-overflow.py`의 `STATES`에 상태를 추가.
  - `dist/index.html`의 "지마켓산스 넘침 방지" CSS 블록은 삭제 금지.
- **화면 배율은 1.0 기준 (2026-11-08)**: 예전에는 게임 화면 전체를 CSS `zoom` 0.9로 줄여 보였는데, 효과 위치가 배율만큼 어긋나는 문제가 반복돼 없앴다. 지금 값이 곧 화면 크기다. `zoom`·`transform: scale`로 화면 전체를 줄이거나 `--ui-scale` 같은 배율 변수를 다시 넣지 않는다(`11_qa/regression/ui-scale-1.test.js`가 막는다). 예전 `?scale=` 주소 옵션도 없어졌다. 경위는 `docs/plan-ui-scale-1.md`.
- **필드 기준 연출**: 스킬/마법/궁극기 연출은 화면 전체가 아니라 `.arena`(필드) 중앙에 표시합니다 (`--field-*` 변수, 뷰포트 단위 vw/vh 사용 금지).
- 규칙 변경 시 `11_qa/regression/ui-contract.test.js`의 계약 테스트도 함께 갱신합니다 (문구·구조를 문자열로 확인하는 테스트가 많음).

## 6. 구조상 주의

- 루트 `README.md`는 "`dist/`는 빌드 결과물이라 직접 수정하지 않는다"고 하지만, **현재는 `dist/index.html`이 규칙과 UI가 들어 있는 원본 파일**입니다 (직접 수정). `dist/runtime/cards.js`만 빌드 결과물입니다.
- `03_card-data/sets/*.json`은 `.gitignore`의 `*.json` 규칙에 걸려 **git에 올라가지 않습니다.** 카드 데이터 변경은 로컬에만 있고, 커밋되는 건 빌드 결과(`cards.js`)뿐입니다 → [09](09-decisions-and-open-issues.md).
- 같은 파일(`dist/index.html`)을 여러 작업자/세션이 동시에 수정하면 변경이 한 줄에 섞입니다. 커밋 전에 자기 변경만 골라 담았는지 확인하세요.
