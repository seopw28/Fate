# 03. 카드와 효과

## 공통 마법 발동 연출 원칙

- 내 마법과 상대 마법 모두 카드명·일러스트·효과 설명을 중앙 발동 애니메이션으로 먼저 보여준 뒤 실제 효과를 적용합니다.
- 피해·회복·강화·부활·전장 전체 파괴 등 결과 판정은 발동 안내보다 먼저 실행되면 안 됩니다. 내 세트 마법은 안내 시작 약 0.82초 뒤, 상대 마법은 약 0.9초 뒤 효과를 적용합니다.
- 같은 시점에 여러 마법이 준비되면 각각의 발동 안내와 효과를 순서대로 처리합니다. 특히 전장 전체 파괴는 카드 공개 없이 필드 카드가 먼저 사라지는 상황을 금지합니다.

> 카드 수치(비용·공격력·체력·피해량)의 **원본은 `03_card-data/sets/*.json`** 입니다. 이 문서는 카드 **종류와 효과 규칙**만 다룹니다.
> 카드 텍스트의 원본은 `dist/index.html`의 `runtimeRulesText()` 입니다.

## 1. 카드 종류

| 종류 | 덱에 포함 | 얻는 방법 | 쓰는 법 |
|---|---|---|---|
| 챔프 | O (기본 덱 45장) | 소환(가챠), 시작 카드 | 선택 → 다시 눌러 소환 (마나 지불) |
| 마법 | O (기본 덱 9장) | 소환(가챠), 시작 카드 | 선택 → 세팅. **다음 필드(내 다음 턴 시작)에 자동 발동** |
| 함정 | O (기본 덱 6장) | 소환(가챠), 시작 카드 | 선택 → 세팅. **조건이 맞으면 자동 발동** |

- 소환 방법: 카드를 한 번 눌러 선택하고 **다시 한 번 누르면 사용**됩니다(드래그로 필드에 놓아도 됨).
- 모든 카드는 성격 오라(불·물·나무·금속·대지), 희귀도(일반·희귀·전설), 비용을 가집니다.

## 2. 등급 (뽑는 순간 굴림)

카드를 뽑을 때마다 공격력 보너스가 정해집니다. 같은 카드도 뽑을 때마다 등급이 다를 수 있습니다. 상대 카드도 똑같이 굴립니다.

| 등급 | 확률 | 공격력 보너스 |
|---|---|---|
| C | 50% | +0 |
| B | 35% | +1 |
| A | 15% | +2 |

## 3. 마법·함정 세팅 규칙

- 슬롯은 **2칸**. 가득 차면 새로 세팅할 수 없습니다.
- 세팅할 때 마나(비용)를 지불합니다. 턴 종료 전에는 **취소해 손패로 되돌릴 수 있고**(슬롯 더블클릭 또는 손패로 드래그) 이때 쓴 마나/혈마나 체력이 환불됩니다.
- **마법(능동형)**: `세팅한 턴 + 대기 턴수`가 지나면 내 턴 시작 때 자동 발동합니다. 대기 턴수 기본값은 1이며 카드별로 다릅니다(예: 전역 파괴 5턴).
- **함정(반응형)**: 세팅한 다음 필드부터 조건을 감시합니다. 한 번 발동하면 사라집니다.

| 함정 | 발동 조건 | 효과 |
|---|---|---|
| 서먼 널리파이어 | 상대가 챔프를 소환 | 그 챔프의 소환을 무효화하고 제거 |
| 매복 지뢰 | 상대가 챔프를 소환 | 그 챔프에게 4 피해 |
| 역류 장벽 | 상대가 내 영웅을 공격 | 그 공격의 피해를 막고 공격자에게 3 피해 |
| 라스트 스탠드 | 내 챔프가 1장뿐이고 적이 3장 이상 | 그 챔프 +5/+5, 보호막, 공격 기회 |

## 4. 효과 사전

### 4-1. 소환 시 효과 (챔프)

| 효과 | 내용 |
|---|---|
| 프로스트 록 (`freeze-strongest`) | 가장 강한 적에게 공격 −2, 다음 공격 동결 |
| 쇠약 (`weaken-all`) | 모든 적의 공격력 −1 |
| 디멘션 이지스 (`blink-shield`) | 보호막 + 즉시 행동 가능 |
| 아케인 애로우 (`arcane-arrow`) | 상대 영웅에게 2 피해 |
| 광역 치유 (`mass-heal`) | 모든 아군 체력 +2 |
| 힐링 블레스 (`heal-bless`) | 가장 약한 아군 +3 회복 + 보호막 |
| 전투 강화 (`battle-enhance`) | 모든 아군 공격력 +1 |
| 늑대 소환 (`summon-wolf`) | 2/2 마력 늑대 토큰 |
| 소드 오라 (`sword-aura`) | 가장 왼쪽 적에게 3 피해 |
| 블레이즈 하트 (`flame-awakening`) | 자신의 공격력 +1 |
| 아쿠아 그레이스 (`tide-grace`) | 내 영웅 체력 +2 |
| 테라 이지스 (`stone-aegis`) | 보호막 |
| 페이트 콜 (`fate-draw`) | 카드 1장 드로우 |
| 게일 러시 (`rush`) | 소환한 턴에도 즉시 공격 |
| 불가침 (`turn-invulnerable`) | 소환한 턴 동안 모든 피해 무효 (현재 이 효과를 쓰는 카드는 없음) |
| 고독 (`lone-wolf`) | 내 전장에 혼자일 때 공격 +3, 체력 +2 |

### 4-2. 공격·피격 시 효과 (챔프)

| 효과 | 내용 |
|---|---|
| 화상 (`burn`) | 공격한 대상에게 화상 +1 |
| 폭발 표식 (`explosive-mark`) | 공격마다 표식, 3개에서 4 피해 폭발 |
| 관통 마탄 (`piercing-shot`) | 공격 후 다음 적에게 관통 피해 2 |
| 관통 (`armor-pierce`) | 대지 오라의 치명타 생존 판정을 무시 |
| 충격 저장 (`shock-storage`) | 피해를 받으면 다음 공격 +2 저장 |
| 사령술 (`necromancy`) | 아군이 쓰러지면 라운드당 1회 2/2 사령 소환 |
| 수적 우위 (`swarm-fury`/`swarm-bulwark`) | 적 챔프 수에 비례해 공격력 상승/받는 피해 감소 |

## 5. 카드 추가·수정 절차

1. `03_card-data/sets/`의 JSON에 카드를 추가·수정합니다 (`cardId`, 비용, `aura`, 희귀도, 스탯, `effects`, `assetId`).
2. 새 효과 ID를 만들면 `validate-cards.mjs`의 `allowedEffects`에 등록하고, `dist/index.html`에 동작과 `runtimeRulesText()` 문구를 추가합니다.
3. `npm run build:runtime` → `dist/runtime/cards.js` 생성. `npm test`로 검증.
4. **챔프 카드는 목록 맨 끝에 추가**하세요. 저장 데이터가 카드 순번에 의존하므로 중간 삽입·삭제는 사고 위험입니다 → [06](06-economy-and-deck.md), [09](09-decisions-and-open-issues.md).
5. 카드 일러스트는 정사각형 PNG/WebP. 마법/함정은 `assetId`가 이미지 확장자로 끝나야 일러스트가 표시됩니다(없으면 이모지 아이콘).
6. **여성 캐릭터만 등장**하는 게임입니다. 남성 캐릭터·몬스터 일러스트는 넣지 않습니다 → [09](09-decisions-and-open-issues.md).

## 빙결·번개 효과와 신규 마법 (2026-11-02)
- 빙결과 번개는 성격 오라가 아니라 카드 효과와 연출 명칭입니다. 모든 카드 분류와 전투 판정은 성격 오라 5종만 사용합니다.
- 기존 카드 16장을 재분류했습니다. 빙결: 빙결검 에스텔·8써클 시엘라·유키의 타냐·설아린·설연화·계설아·서한설·소연, 마법 프로스트 노바·Glacial Chain. 번개: 세라피나·단목령·연시아·진소소·한소려·설리.
- 궁극기: 빙결 `혹한의 감옥`(모든 적 피해 + 동결), 번개 `벽력 연쇄`(모든 적 챔프와 상대 영웅에게 피해). 피해량은 ⌈공격력/2⌉+3이며 속성별 추가 발동 조건은 없습니다.
- 신규 마법: 낙뢰(비용 3, 가장 공격력 높은 적에게 4 피해), 연쇄 번개(비용 4, 공격력 상위 3장에 5·4·3), 천벌(전설 비용 6, 7·6·5), 서리 감옥(비용 3, 가장 강한 적에게 2 피해 + 동결). 시뮬레이터 `spell-balance.mjs`의 `chain` 유형으로 비용·피해 균형을 확인(연쇄 번개 4/5 → +8.5%p, 천벌 6/7 → +17%p).

## 다수 공격 챔피언 (2026-11-02)
고코스트(7 이상) 챔피언 17장에 "여러 명을 한 번에 공격하는" 효과를 줬습니다. 다수 공격은 가치가 높아서 같은 코스트의 표준 카드보다 능력치를 깎아 균형을 맞췄습니다.

| 효과 | 내용 | 능력치 합(표준 대비) |
|---|---|---|
| 소환 시 전체 공격 (`summon_barrage`) | 소환(세팅)할 때 적 챔프 전체에게 N 피해. 영웅·아군은 맞지 않음 | N=2 → 약 85%, N=3 → 약 77% |
| 기본 공격 전체 (`sweep_attack`) | 기본 공격이 적 챔프 전체를 공격력의 P%로 때림(적이 없으면 영웅에게 전체 공격력) | P=50 → 약 87%, P=70 → 약 73% |

- 시뮬레이터 `09_balance-lab/match-simulator/champion-balance.mjs`로 측정(`--solve --cost 8 --effect barrage:3`). 같은 코스트의 표준 챔피언과 맞붙어 승률 50%가 되는 능력치 합을 찾았다.
- 코스트별 표준 능력치 합(실제 카드 평균): 2→6.0, 3→7.7, 4→9.3, 5→10.9, 6→12.8, 7→15.8, 8→18.4, 9→21.8.
- 상대(AI) 챔프는 원래 능력치만 쓰고 개별 효과는 쓰지 않으므로 이 효과도 내 챔프에게만 적용된다.
- 적용 카드: 코스트 9 — 리베르나·백연주(전체 기본공격 70%), 천희령(50%), 몽리·악신 바알(소환 시 3). 코스트 8 — 도홍·적화린(50%), 9써클 리제엘(소환 시 3), 바알계약 유리아·아스테라·적하륜(소환 시 2). 코스트 7 — 아리엘·무영·홍설(50%), 낙인자 클로에·설유화·진조 리리엘(소환 시 2).

## 궁극기 균형 점검 (2026-11-02)
궁극기를 쓰는 것과 같은 카드를 일반 소환하는 것의 가치가 비슷해야 한다. 시뮬레이터(`spell-balance.mjs --vs-champion 비용:합 --eval aoe:궁극기비용:피해:0:사용라운드`)로 전체 피해 궁극기(물·빙결·번개)를 일반 소환과 비교했다.
- 강한 카드(기본 비용 5 이상 또는 공격력 7 이상): 비용 9 / 피해 6 → 50.8%, 비용 10 / 피해 7 → 52.3%, 비용 10 / 피해 8 → 47.7%. 균형이 맞아 수식(`⌈공격력/2⌉+3`)을 유지했다.
- 약한 카드(기본 비용 4 이하): 같은 수식으로는 비용 3 → 38%, 비용 4 → 46%로 일반 소환보다 약했다. 피해를 `4 + 기본 비용`(비용 2→6, 3→7, 4→8)으로 올렸다(비용 4: 53%, 비용 3: 45%, 비용 2: 43%).
- 화염·바람·대지·무오라 궁극기는 시뮬레이터가 영웅 직접 피해, 아군 강화, 무적 등을 모델링하지 못해 이번에는 조정하지 않았다.
