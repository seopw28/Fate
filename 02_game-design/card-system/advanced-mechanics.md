# 고급 카드 메커니즘 운영 규칙

## 이번 기반에서 지원하는 첫 세 축

- **숙성**: 라운드 시작마다 카운터가 쌓이고 기준치에 도달하면 다른 카드 정의로 변신한다.
- **각성**: 피해 처리 후 체력 비율 같은 조건을 검사해 강화 형태로 변신한다.
- **종말**: 예약된 시점에 양측 필드의 모든 챔피언을 제거한다.

효과는 카드별 임시 코드가 아니라 공용 효과 레지스트리에서 실행한다. 알 수 없는 효과는 조용히 무시하지 않고 명시적으로 실패시켜 카드 데이터와 실행 코드의 불일치를 조기에 발견한다.

## 출시 상태와 UI 노출

- `live`: 수집, 덱 편집, 보상 후보에 노출할 수 있다.
- `prototype`: 규칙과 밸런스 검증용이다. 기존 수집 UI에는 노출하지 않는다.
- `retired`: 신규 획득과 덱 추가 대상에서 제외한다. 보유 이력 처리 정책은 별도로 둔다.
- 변신 결과처럼 직접 수집하지 않는 형태는 `collectible: false`로 둔다.

프로토타입을 `live`로 승격하려면 카드 아트, 문구, 획득처, AI 사용 규칙, 상호작용 테스트, 기본 밸런스 검증이 모두 준비되어야 한다.

## 다음 구현 순서

1. 지속·성장: 숙성, 충전, 소모성 카운터
2. 조건·형태 전환: 각성, 태세 변경, 선택형 능력
3. 전장 규칙: 종말, 지형, 양측 대칭 효과
4. 관계·서사: 특정 캐릭터 조합, 라이벌, 희생과 계승
5. 덱 정체성: 원소·종족·비용 곡선 조건과 덱 구축 보상

각 단계는 공용 스키마와 결정적 테스트를 먼저 추가하고, UI는 준비된 카드만 점진적으로 노출한다.
