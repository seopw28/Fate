# 02 Game Design

코드보다 먼저 합의해야 하는 게임 규칙과 콘텐츠 시스템을 명세합니다.

## 영역

- `core-rules/`: 턴 구조, 승패, 전투, 자원
- `card-system/`: 카드 유형, 오로라, 키워드
- `deck-building/`: 덱 크기와 편성 제한
- `progression/`: 해금과 성장
- `game-modes/`: 튜토리얼, PvE, PvP
- `economy/`: 팩, 제작, 재화
- `game-rules/`: **현재 구현된 게임 규칙 전체 정리 (PM 인수인계용)** — [game-rules/README.md](game-rules/README.md)

모든 규칙에는 예시와 예외 상황을 함께 적습니다.
