# Base AI Prompt

아래 대괄호 항목을 효과 사양에 맞게 교체한다.

## 생성 프롬프트

투명 배경의 2D 판타지 카드게임 스킬 이펙트 텍스처. 효과 의미는 `[semantic]`, 핵심 모티프는 `[motif]`. 색상은 `[palette]`만 사용한다. 중심점이 정확히 고정되고 가장자리에 충분한 투명 여백이 있어야 한다. 작은 전장 카드 위에서도 형태를 알아볼 수 있는 굵고 단순한 실루엣. 글자, 숫자, 로고, 인물, 캐릭터, 무기, 카드 프레임, UI 패널은 포함하지 않는다. `[entry]`에서 시작해 `[peak]`가 가장 강한 형태이며 `[exit]`로 자연스럽게 사라지는 애니메이션 제작에 적합해야 한다. 정면 직교 시점, 고대비 알파, 게임 합성용, 독창적인 비주얼 언어.

## 네거티브 조건

- 불투명 배경
- 읽을 수 있는 문자 또는 워터마크
- 실사 인물과 신체 부위
- 특정 게임이나 작가를 연상시키는 고유 디자인
- 지나치게 가는 선과 작은 장식
- 잘린 입자와 프레임 밖 발광
- 중심점이 흔들리는 연속 프레임

## 권장 출력

- 정적 텍스처: 투명 PNG, 512×512
- 스프라이트 시트: 투명 PNG, 5×4 또는 6×4 그리드
- 후보 수: 동일 사양 4개
- 원본 보존: 모델명, 생성일, 전체 프롬프트와 입력 참조를 메타데이터로 기록
