# Effect Quality Checklist

## 의미 전달

- [ ] 첫 300ms 안에 피해·회복·방어·강화 중 무엇인지 구분된다.
- [ ] 색상을 제거해도 실루엣과 움직임으로 의미가 구분된다.
- [ ] 발동 주체와 대상이 혼동되지 않는다.

## 화면 품질

- [ ] 카드명, 공격력, 체력과 HP 숫자를 가리지 않는다.
- [ ] 밝은 배경과 어두운 배경에서 모두 외곽이 선명하다.
- [ ] 작은 전장 카드와 소환사 아바타에서 중심점이 맞는다.
- [ ] 알파 가장자리에 흰색 또는 검은색 테두리 오염이 없다.

## 모션

- [ ] 시작·정점·종료가 명확하며 불필요하게 오래 남지 않는다.
- [ ] 스프라이트 프레임 사이에서 크기와 중심점이 흔들리지 않는다.
- [ ] 반복 점멸이나 과도한 화면 흔들림이 없다.
- [ ] 저감 모션 대체안에서도 효과 의미가 유지된다.

## 성능과 운영

- [ ] 사양의 텍스처, 용량, 파티클 예산을 지킨다.
- [ ] 동시에 세 효과를 재생해도 프레임 저하가 심하지 않다.
- [ ] 생성 모델, 프롬프트, 생성일과 출처가 기록됐다.
- [ ] 승인 자산만 `06_assets/vfx/`와 배포 빌드에 포함된다.
