# Game Events Contract

엔진이 발생시키고 클라이언트·봇·리플레이가 소비하는 이벤트의 정본 위치입니다.

각 이벤트에는 아래 항목이 필요합니다.

- 고유한 이벤트 종류와 버전
- 게임 및 턴 식별자
- 원인 액션과 발생 순서
- 공개 정보와 플레이어별 비공개 정보의 구분
- 직렬화 가능한 페이로드

애니메이션 완료 여부가 규칙 진행을 막지 않도록 게임 이벤트와 화면 연출 이벤트를 분리합니다.

## 현재 계약

- 캐릭터챗 카드 지급: `reward-granted.schema.json`
- 결정론적 매치 이벤트: `04_game-engine/src/engine.js`
- 캐릭터챗 보상 멱등 처리: `10_platform/account/inventory-ledger.js`

`rewardEventId`는 동일한 보상이 재전송되어도 카드가 중복 지급되지 않도록 보장하는 키입니다.
