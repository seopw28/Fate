# Ideation

게임 개선 아이디어를 구현 코드와 분리해 관리하는 공간입니다.

## 문서 목록

- [`card-improvement-ideas.md`](card-improvement-ideas.md): TCG 카드의 규칙, 정보 구조, 시각 디자인 개선 목록

## 상태 기준

- `Proposed`: 검토 전 아이디어
- `Selected`: 구현하기로 결정
- `In Progress`: 구현 중
- `Done`: 구현 및 검증 완료
- `Deferred`: 현재 범위에서 보류
- `Rejected`: 근거를 기록하고 제외

아이디어를 구현할 때는 상태만 바꾸지 않고 관련 코드와 검증 결과를 함께 연결합니다.
