# Character image sources

게임 카드에 사용한 외부 이미지의 출처와 로컬 파일 대응표를 관리하는 폴더입니다.

- 원본 페이지와 개별 이미지 URL: `sources.json`
- 게임용 로컬 파일: `../dist/assets/characters/collected/`
- 수집일: 2026-10-30

외부 원본이 바뀌거나 내려가도 게임이 깨지지 않도록 이미지는 로컬에 저장하며, 새 이미지를 추가할 때는 `sources.json`에 출처와 파일명을 함께 기록합니다. 공개·상업 배포 전에는 각 원본의 사용 권한을 별도로 확인해야 합니다.
