# 오라별 기본 덱 5종 + 새 캐릭터 추가 (2026-11-09)

## 요청

- 5개 오라(불·물·나무·금속·대지)마다 맞춘 덱을 기본 덱으로 고를 수 있게 한다.
- 링크 4곳의 캐릭터를 하수인 카드로 추가한다. 같은 카드를 여러 장 넣어도 된다.
- 덱 60장 구성
  - 하수인 30장: 덱 오라 20장 + 다른 오라 10장
  - 마법 20장 + 함정 10장: 덱마다 거의 같아도 된다.

## 현황 (실측)

- 덱 규칙은 이미 있다: 60장, 하수인 30·마법 20·함정 10, 같은 카드 최대 7장, 같은 오라 최대 30장.
- 기본 덱(`buildBasicDeck`)은 무작위로 채운다. 처음 보유는 일반 하수인 8장씩뿐이다.
- 오라별 일반 하수인 수가 크게 다르다: 불 11, 물 6, 나무 8, 금속 5, 대지 13. 그래서 오라 덱을 만들면 금속·물이 약하다.
- 컴퓨터 덱도 같은 무작위 기본 덱이다.

## 단계

- [x] 1. 이미지 48장을 받아 `dist/assets/characters/<세트>/`에 webp로 저장하고 `collection-sources/sources.json`에 출처를 적는다.
- [x] 2. 카드 데이터 48장을 `character-expansions.json`에 추가한다. 일반 위주로 넣어 오라별 일반 하수인 수를 비슷하게 맞춘다. 효과는 기존 카드에 쓰던 효과만 쓴다. `npm run validate:cards` 통과.
- [x] 3. 오라 덱 5종을 `03_card-data/sets/aura-decks.json`에 정의한다. 20장 비용 곡선을 다섯 덱이 똑같이 쓰고, 능력치 합 차이가 작은지 테스트로 막는다.
- [ ] 4. 클라이언트: 덱 편집에서 오라 기본 덱 5종 중 하나를 골라 불러오기. 새로 시작하면 오라 덱 5개가 덱 목록에 들어 있다. 기본 덱에 든 카드는 보유 수를 보장한다.
- [ ] 5. 컴퓨터도 오라 덱 5종 중 하나를 무작위로 쓴다(사람과 같은 규칙).
- [ ] 6. `check-ultimate-rework.py`의 '컴퓨터 턴 흐름: 강림 시점' 검사가 무작위 덱 구성에 따라 복수자 체력이 19/16으로 갈린다(2단계 뒤 실패). 내 전장을 비우고 재는 식으로 덱과 무관하게 고친다.
- [ ] 7. 문서 갱신, `npm test`, 스크린샷 확인, 커밋·브랜치 push. 배포는 요청 시.
