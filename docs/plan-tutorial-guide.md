# 새 튜토리얼: 기능 시연 가이드 (2026-11-09 PM 요청)

전투와 별개인 연출 전용 화면에서 주요 기능 6개를 차례로 보여 준다. 단계마다 짧은 애니메이션 시연이 나오고, 유저가 빛나는 버튼을 한 번 눌러야 다음 단계로 넘어간다. 전투 규칙은 돌지 않으며 카드, 마나, 체력은 연출용이다.

## 순서 (PRD 1-4)

| 단계 | 기능 | 시연 | 유저가 누를 것 |
|---|---|---|---|
| 1 | 카드 뽑기 | 덱에서 카드가 손패로 날아오고, 다음 비용이 2 → 4 → 8로 오른다 | 카드 뽑기 버튼 |
| 2 | 카드 순서 바꾸기 | 전장 하수인 둘이 자리를 바꾸고, 맨 왼쪽이 먼저 맞는다는 표시 | 빛나는 하수인 → 맨 왼쪽 칸 |
| 3 | 오라 마법 | 남은 마나가 모두 빠져 상대 소환사에게 날아감, 3턴 쿨다운 표시 | 오라 마법 버튼 |
| 4 | 묘지 회수 | 손패 마법 1장이 부서지고, 묘지에서 하수인이 솟아 손패로 날아옴 | 묘지 회수 버튼 → 제물 카드 |
| 5 | 오라 각성 | 체력이 85 이하로 떨어지며 버튼이 열리고, 강화 2개 중 하나를 고름 | 오라 각성 버튼 → 강화 하나 |
| 6 | 영웅 강림 | 손패 하수인이 떠오르고 같은 오라 카드가 빛남, 소진자 등장 | 영웅 강림 버튼 → 빛나는 카드 |

## 결정 (PM)
- 전투와 별개, 시연 뒤 따라 누르기, 순서는 위 표 (notes 11/9).
- 상단 튜토리얼 토글(전투 중 단계별 설명, 컴퓨터 실수 확률 증가)을 없애고 새 튜토리얼로 대체한다.
- 정상 완료 시 계정당 최초 1회 100크래커, 건너뛰면 0. 진행 중 건너뛰기 가능, 메뉴에서 다시 시작 가능 (PRD 1-4 현행).

## 임시 결정 (PM 확인 전)
- 진입: 상단 토글 자리에 `튜토리얼` 버튼을 두고 누르면 연다. 목업에는 첫 접근 선택 화면이 없으므로, 처음 방문한 브라우저에서는 자동으로 한 번 연다.
- 단계 시연은 3~4초, 끝나면 반복 재생 버튼을 둔다. 설명 문구는 Claude 초안이다.
- 시연 카드는 실제 카드 데이터의 그림을 빌려 쓴다. 성격 오라는 불로 고정한다.
- 화면 아래에 6칸 진행 표시와 `건너뛰기`를 둔다. 건너뛰면 보상 없이 닫는다.
