# 영웅 강림: 궁극기 슬롯 없이 손패에서 바로 고르기 (2026-11-09 PM 요청)

궁극기 슬롯이 사용 난이도를 올려서, 슬롯 세팅 단계를 없앤다.
영웅 강림 버튼이 깜빡일 때 누르면 손패의 하수인 카드가 전장 위로 떠오르고, 같은 오라 카드는 빛난다. 카드를 누르면 즉시 영웅(소진자)이 소환된다.

## 임시 결정 (PM 확인 전, 목업에 먼저 반영)
- 영웅 강림 버튼 활성 조건: 세팅 단계 + 오라 각성 완료 + 재세팅 잠금 없음 + 손패에 지금 마나로 부를 수 있는 하수인이 1장 이상.
- 비용은 그대로(최대 마나, 같은 오라면 −2). 마나가 모자란 카드는 떠오르되 흐리게 표시하고 고를 수 없다.
- '세팅한 다음 턴부터 발동' 규칙은 없앤다(고르는 즉시 소환).
- 고른 카드의 덱 사본은 지금처럼 모두 사용 처리한다.
- 선택 화면은 빈 곳 클릭, 취소 버튼, Esc로 닫는다.
- 컴퓨터도 같은 규칙: 강림할 수 있는 턴에 손패에서 부를 수 있는 카드를 골라 즉시 강림한다.

## 체크리스트
- [x] 1. 궁극기 세팅 패널을 숨기고, 영웅 강림 버튼 활성 조건을 손패 기준으로 바꾼다
- [x] 2. 버튼을 누르면 손패 하수인을 전장 위에 띄우는 선택 화면(같은 오라 빛, 마나 부족 흐림)
- [x] 3. 카드를 누르면 즉시 소진자 소환 (세팅 + 발동을 한 번에)
- [x] 4. 컴퓨터를 같은 규칙으로 (고르는 즉시 강림)
- [x] 5. 잠금 문구의 '세팅'을 '강림'으로 바꾸고 QA·테스트 갱신
- [x] 6. 전체 테스트·QA, 스크린샷 확인, 커밋
