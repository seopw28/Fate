# 덱마다 오라 필수 · 오라당 덱 1개 · 오라 선택 시 매칭 덱 자동 적용 (2026-11-09)

## 요청

- 덱 편집에서 덱마다 오라를 반드시 지정한다.
- 한 오라에는 덱이 최대 1개만 매칭된다.
- 전투 시작 때 성격 오라를 고르면 그 오라에 매칭된 덱을 자동으로 가져온다.

## 정한 규칙 (PM 확인 전 임시)

- 오라가 5종이므로 덱은 최대 5개다(이전 6개).
- 덱 오라는 덱 편집의 `오라` 선택으로 바꾼다. 다른 덱이 쓰는 오라는 고를 수 없다.
- 새 덱·복제는 비어 있는 오라가 있을 때만 된다. 비어 있는 첫 오라가 붙는다.
- 기존 저장 마이그레이션
  - 덱 이름이 오라 덱 이름(불의 덱 등)이면 그 오라를 붙인다.
  - 그 밖에는 하수인이 가장 많은 오라를 붙이고, 이미 쓰였으면 남은 오라 중 첫 번째를 붙인다.
  - 덱이 6개면 오라를 받지 못한 마지막 덱은 지운다.
- 오라를 골랐는데 매칭된 덱이 없거나 60장이 아니면 그 오라의 기본 덱을 쓴다.
- 오라를 고르기 전 덱과 시작 손패는 임시다. 고르는 순간 매칭된 덱으로 다시 섞고 시작 손패를 다시 뽑는다.
- 컴퓨터도 같은 방식이다. 컴퓨터 오라가 정해지면 그 오라의 기본 덱으로 다시 섞고 손패를 다시 뽑는다.
- `메인 덱 지정`은 없앤다. 덱 탭에는 메인 덱 대신 오라를 표시하고, 저장 버튼 자리에는 "○ 오라를 고르면 이 덱으로 싸웁니다" 안내를 둔다.
- `오라 기본 덱 불러오기`는 편집 중인 덱의 오라 기본 덱으로 채우는 버튼(`기본 덱으로 채우기`)으로 바꾼다.
